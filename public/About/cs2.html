COMPUTER SCIENCE II

Computer Science II teaches students to design, organize, build, test, and maintain larger software applications using object-oriented programming, data structures, algorithms, and systematic software engineering practices.

I. Software Development

  1. Design larger software applications. Identify requirements, divide a program into manageable components (decomposition), design reusable functions with clear inputs, outputs, parameters, and return values, and plan how the parts work together. Program design, functional decomposition, top-down design, bottom-up design, and black-box design. <DESIGN-1>
  2. Build reusable software by organizing related data and behavior into classes and objects. Use abstraction (hide implementation details), encapsulation (keep related data and behavior together), inheritance (extend an existing class; an “is-a” relationship), interfaces (define common behavior), object composition (build objects from other objects; a “has-a” relationship), and polymorphism (write one function that works with different object types through a common interface). <OOP-1>
  3. Manage application state. Use state variables, control structures, Boolean logic, nested logic, and other programming techniques. <STATE-1>
  4. Store and organize application data. Use appropriate data structures, including strings, arrays, matrices, dictionaries, and sets. <DATA-1>
  5. Process and transform data. Use algorithms and data structures, including loops, recursion, searching, sorting, insertion, deletion, and string processing. <DATA-2>
  6. Compare algorithm efficiency. Use informal runtime observations, operation counts, and Big-O notation, including best-case, average-case, and worst-case behavior. <ALG-1>
  7. Test, debug, and improve software. Identify compile, syntax, runtime, and logic errors; test normal and boundary cases; test functions, classes, or libraries separately when useful; and improve code through controlled, incremental changes. Systematic testing means selecting test cases intentionally rather than merely trying the program until it appears to work. <TEST-1>
  8. Integrate libraries and APIs. Integrate external libraries and APIs into an application, using their documentation as needed. <INTEGRATE-1>
  9. Collaborate on larger software projects. Plan a solution with others, divide responsibilities, build compatible components, test the combined solution, and communicate the results. <TEAM-1>

II. Career and Professional Skills

  1. Explore computer science education and careers. Research jobs, internships, certifications, résumés, portfolios, companies, and university computer science programs. <CAREER-1>
  2. Practice technical communication. Read technical materials, write clearly about software, document work, and present the purpose and results of a project. <COMM-1>
  3. Develop professional work habits. Practice planning, time management, leadership, teamwork, critical thinking, and responsible professional behavior. <PROF-1>

III. Additional Required Topics

  1. Use short-circuit Boolean evaluation and simplify Boolean expressions using De Morgan’s Law. <STATE-1>
  2. Use mathematics libraries and numerical algorithms. <DATA-2>
  3. Use random-number generation to create simulations. <DATA-2>
  4. Distinguish value behavior from reference behavior when passing or storing data. <OOP-1>
  5. Compare objects by content rather than merely by identity, where the programming language makes that distinction. <OOP-1>
  6. Explain shallow copying and deep copying. <OOP-1>
  7. Use access controls, object creation, getters and setters or equivalent property access, and object mutation. <OOP-1>
  8. Use multi-way selection where appropriate, such as a switch statement. <STATE-1>
  9. Use type conversion when processing data. <DATA-2>
  10. Read, write, and process files, including files where the number of records is not known in advance. <FILE-1>
  11. Compare machine language, assembly language, compiled languages, interpreted languages, and scripting languages. <LANG-1>
  12. Work with binary, decimal, octal, and hexadecimal representations, and explain integer boundaries, floating-point imprecision, and round-off errors. <REP-1>
