Lesson II: Creating Radio Buttons

Radio buttons allow one option to be selected from a group. Selecting one option deselects the others.

Radio buttons with the same name belong to the same group.

const easyOption = document.createElement("input"); easyOption.type = "radio"; easyOption.name = "difficulty"; easyOption.value = "easy"; const hardOption = document.createElement("input"); hardOption.type = "radio"; hardOption.name = "difficulty"; hardOption.value = "hard"; document.body.append(easyOption, hardOption);

Check whether it's selected

if (optionA.checked) { // do something } // or use if (optionA.value = "Option 1") { // do something }

Use if option.checked or if option.value.

Lesson III: Creating a Dropdown Menu

A dropdown menu uses a select element containing several option elements.

To access the selected value: const selectedValue = menu.value;

// create Menu Box const menu = document.createElement("select"); document.body.append(menu); // create Option A const easyOption = document.createElement("option"); easyOption.textContent = "Easy"; easyOption.value = "easy"; // create Option B const hardOption = document.createElement("option"); hardOption.textContent = "Hard"; hardOption.value = "hard"; // Add Elements to Menu Box menu.append(easyOption, hardOption);
