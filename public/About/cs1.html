COMPUTER SCIENCE I OVERVIEW

I. Software Development

A. Programming (TypeScript)

  1. Use and manipulate variables. Explain how references and basic types work, and work with math, strings, Booleans, and optional values. <PROG-1>
  2. Write readable TypeScript that breaks work into functions (with arguments, return values, local vs. global scope). <PROG-2>
  3. Use standard control structures, including if-then statements ("selection") and loops ("iteration"). <PROG-3>
  4. Divide code into modules. Use object-oriented programming. Explain the importance of abstraction. <PROG-4>

B. UI (HTML/CSS)

  1. Add HTML elements to HTML files. Create HTML elements or link them programmatically, including labels, images, and user input boxes. <UI-1>
  2. Define size, shape, position, and color using CSS or code. Modify other HTML element styles or properties with the help of reference materials or AI. <UI-2>
  3. Use flexboxes to create modern web page or app layouts. <UI-3>
  4. Present input and output clearly, using labels, prompts, formatted displays, and simple visual elements such as lines, circles, and rectangles. (Texas wants students to create vector graphics.) <UI-4>
  5. Create a modern master-detail app, featuring a dynamic table of items, an item detail page, and some navigation between pages (or, if a one-page app, the appearance of such). <UI-5>

C. Real-World Tools & Frameworks

  1. Write Progressive Web Apps using Visual Studio (or other real-world tools) starting from a basic template/project file. <TOOLS-1>
  2. Use the terminal to run the development environment and run code in a browser. <TOOLS-2>
  3. Use the text editor and browser inspector to debug simple programs—reading short code segments, tracing variable values, predicting output, and explaining program behavior. <TOOLS-3>
  4. Test programs with valid and invalid input, identify common error types, and handle simple errors such as division by zero or bad inputs. <TOOLS-4>
  5. Save persistent data within an app. <TOOLS-5>
  6. Make a simple network call and deserialize input. <TOOLS-6>

D. Algorithms & Data Structures

  1. Implement linear search and binary search (requires sorted data). <ALG-1>
  2. Explain how popular sorting algorithms work, including selection sort, insertion sort, and merge sort with best-, average-, and worst-case performance scenarios. <ALG-2>
  3. Use arrays, dictionaries, and sets in student projects, and explain what they do and how they work. <ALG-3>
  4. Use recursive functions, discuss computational complexity, and determine Big O for simple cases. <ALG-4>

E. Creative Dev (Process)

  1. Design (plan) an app. Illustrate it visually (storyboard/flowchart). Define user interaction and experience. Define program structure, including inputs, outputs, navigation, and tasks. <DEV-1>
  2. Use Agile to work on a team to develop a program. (And be familiar with some of the other paradigms.) Experience daily standups, peer reviews, and timeboxing (a task will often fill up the amount of time you have). <DEV-2>
  3. Use Design Thinking to formulate and iterate on an app. <DEV-3>
  4. Demo apps and document code. <DEV-4>

II. How Does It Work?

A. Computers

  1. Explain the differences between high- vs. low-level languages, compiled vs. interpreted languages, and strongly typed and untyped programming languages. <COMP-1>
  2. Explain how source code moves through a compiler/interpreter to machine code, how the operating system coordinates the process (processes, files, memory, devices), and the role of major computer components (CPU, memory, storage, input/output devices). <COMP-2>
  3. Explain how computers have evolved historically from clockwork to the modern computer. (Students are encouraged to think about how they might have built a computer from scratch.) <COMP-3>
  4. Explain how data is stored as binary numbers and how primitive types are used to define what data means. (Check off required boxes: bits/bytes, binary, text, color/images, text encoding, numeric limits, floating-point precision, analog-to-digital sampling, data compression, lossless vs. lossy, tradeoffs between quality, size, and transmission speed, convert to binary, and add numbers.) <COMP-4>
  5. Use Boolean logic and truth tables, and discuss how they may be used to build logic gates or analog circuits. <COMP-5>

B. The Internet

  1. Explain how computers route packets across the network and handle congestion and errors. (Shortest path algorithms may be, optionally, introduced here.) <NET-1>
  2. Explain what the network stack is and what application-level programs such as HTTPS, email, and DNS do. <NET-2>
  3. Explain how large problems can sometimes be solved faster by distributing work across multiple computers. <NET-3>
  4. Explain redundancy, fault tolerance, and why systems can keep working when parts fail. <NET-4>

C. Cybersecurity

  1. Explain the roles of encryption and authentication. (Tradeoffs: security vs. convenience.) <SEC-1>
  2. Explain common security threats and attacks such as phishing, malware, weak passwords, and data breaches, along with basic strategies for reducing risk. <SEC-2>

IV. Social & Ethical Impact

A. History of Technology

  1. Explain the historical impact of the telephone and television, providing a template for understanding the Internet today. <HIST-1>
  2. Draw parallels between the history of technology and recent phenomena. <HIST-2>

B. Mechanisms of Power & Control

  1. Discuss and reflect upon the forces that shape us as humans and mechanisms of social control (e.g., Houston Smith). <POWER-1>
  2. Discuss how the collection, manipulation, and representation of data may be used in marketing and propaganda. <POWER-2>
  3. Explain social engineering techniques used in massive online video games. <POWER-3>

C. Ethics

  1. Explore and reflect upon contemporary issues resulting from new technologies. Areas of exploration may include economic disruption, cultural and world systems change, personal agency/protection from harm (e.g., privacy, online bullying, control over public representation, ownership and artistic control, personal or cultural equality). <ETH-1>
  2. Discuss the ethics of design. In this process, contemplate the nature of ethical responsibility, referencing ethical theory (e.g., Utilitarianism, Consequentialism, Aristotle, Clifford). <ETH-2>
  3. Reflect upon how different forces battle to influence how technology is used, designed, and understood, and develop personal prescriptions. <ETH-3>
  4. Demonstrate digital citizenship, and understand copyright, licensing, security hygiene, and privacy. <ETH-4>

V. Other

A. Data Science (Teaser)

  1. Use a program (simulation with a random number seed) to model a process so you can observe possible outcomes. <DATA-1>
  2. Analyze data, finding patterns and making predictions, recognizing that correlation does not mean causation and that there may be biases in the data. <DATA-2>
  3. Communicate information through tables, charts, and visual presentations of data. <DATA-3>

B. Career

  1. Research CS careers. <CAREER-1>
  2. Build a résumé/portfolio. <CAREER-2>
  3. Understand certifications and university options. <CAREER-3>
  4. Practice technical communication, teamwork, leadership, and time-management skills in the context of software development. <CAREER-4>

C. Misc

  1. Explain non-computability: some problems cannot be solved because the question asks a system to fully predict or judge the behavior of arbitrary systems, including possibly itself. That creates self-reference, contradiction, or an infinite space of possible behavior that no fixed algorithm can always settle. <MISC-1>
