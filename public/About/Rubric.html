Computer Science Rubric

This rubric provides general criteria for evaluating work throughout the Computer Science course. For software development projects, use the more specific Software Development Project Rubric below.

Computer Science Rubric

1. Functionality & Completeness

  • Program or project works as intended
  • Required components and features are complete
  • Produces correct results
  • Major bugs are resolved
  • Handles expected inputs and situations
  • Extensions or enhancements are completed when appropriate

TEKS Alignment: Technical / Occupational Skills; Technology / Tools / Processes

2. Code Quality & Technical Design

  • Code is readable and organized
  • Names are clear and meaningful
  • Program structure is logical
  • Functions and classes are used appropriately
  • Data models and data structures are well chosen
  • Algorithms and technical approaches are appropriate
  • Unnecessary repetition or complexity is avoided

TEKS Alignment: Technical / Occupational Skills; Technology / Tools / Processes; Problem Solving / Critical Thinking

3. Problem Solving

  • Breaks problems into manageable parts
  • Develops logical approaches
  • Tests and debugs systematically
  • Uses evidence to identify problems
  • Adjusts when an approach does not work
  • Makes reasonable technical decisions
  • Persists through difficult problems

TEKS Alignment: Problem Solving / Critical Thinking

4. Critical Engagement & Understanding

  • Understands and explains relevant computer science concepts
  • Thinks critically about architecture and design choices
  • Considers alternative approaches and tradeoffs
  • Connects technical work to broader ideas in computing
  • Engages with ethical, social, and philosophical questions
  • Considers privacy, security, accessibility, bias, and other impacts when relevant
  • Forms and supports thoughtful conclusions

TEKS Alignment: Professional, Ethical & Legal Responsibilities; Problem Solving / Critical Thinking; Career / Technical Knowledge

5. Collaboration & Professionalism

  • Works constructively with others
  • Communicates clearly and appropriately
  • Asks useful questions and seeks help appropriately
  • Gives and responds to feedback
  • Uses working time productively
  • Uses technology and resources responsibly
  • Meets responsibilities and deadlines
  • Follows academic integrity, safety, and classroom expectations

TEKS Alignment: Professional Standards / Employability Skills; Communication; Collaboration / Teamwork / Leadership; Safety / Rules / Procedures

Software Development Project Rubric

Each category is scored from 1–10 and the scores are averaged for the final grade.

1. Completeness

Completes assigned requirements and features. A score of 7 (85%) indicates that the core requirements have been met.

2. Professional Practice

Follows professional software development practices and works in a professional manner. Takes ownership of the project, manages work effectively, uses tools and resources appropriately, and responds to feedback.

3. Functionality & User Experience

Does the application run correctly and work as intended? Features behave correctly, significant bugs are absent, and the interface is understandable and reasonably easy for the user to use.

4. Architectural Design & Problem Solving

Designs a clear overall approach to the program. Breaks the problem into manageable parts, determines how they should work together, and chooses appropriate solutions. Adjusts the design when needed.

5. Program Structure

How well is the program divided and organized? Uses appropriate functions, classes, modules, data structures, and other programming structures to give the program a clear organization and sensible separation of responsibilities.

6. Code Quality & Readability

How clear, organized, and maintainable is the code? Uses meaningful names, sensible ordering, appropriate formatting, and code that is reasonably simple and free of unnecessary repetition or complexity. Indentation, spacing, paragraph returns, and consistent formatting make the code easy to read and understand.

Grade Scale

  • 10 — Exceptional — 100%
  • 9 — Excellent — 95%
  • 8 — Strong — 90%
  • 7 — Good — 85%
  • 6 — Satisfactory — 80%
  • 5 — Developing — 75%
  • 4 — Limited — 70%
  • 3 — Weak — 65%
  • 2 — Very Limited — 60%
  • 1 — Minimal — 50%
  • 0 — Missing / No Meaningful Evidence — 0%
