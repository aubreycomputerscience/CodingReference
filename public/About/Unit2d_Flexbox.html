Layout: Three Approaches

1. Default Layout: each element is placed after the last one.

const messageA = document.createElement("p"); messageA.textContent = "Hello"; document.body.append(messageA); const messageB = document.createElement("p"); messageB.textContent = "World"; document.body.append(messageB); // placed below messageA

2. Absolute Coordinates: set x and y position of each element.

const myCharacter = document.createElement("img"); myCharacter.src = "images/character.png"; myCharacter.style.position = "absolute"; // Allows us to use left and top. myCharacter.style.left = 10 + "px"; // x position - how far is it from the left margin myCharacter.style.top = 20 + "px"; // y position (inverted) - how far is it below the top document.body.appendChild(myCharacter);

3. Flexbox: Use rules to divide up the space


The good news: Flexible Layout (will resize for different size types), Fairly Straightfoward

The bad: Can be wonky, brittle, hard to debug

Flexbox: Divide and Conquer

Start with the full page and divide it into boxes. Each box can then arrange the elements placed directly inside it. We will insert 3 elements - header, body, & footer - displayed as three rows. For example: Page ├── Header └── Body └── Footer Next, we can work on the body view. Divide the body into two sections or columns. └── Body ├── Sidebar └── Content This approach will allow us to layout most of the apps on the app store. Think of your favorite app. Divide it up into boxes, using pen and paper.

Flexbox: How To

1. For each view, determine how to arrange the elements inside it. mainView.style.display = "flex"; mainView.style.flexDirection = "column"; // it is a column, so contains rows
2. Then, each subview must specify how much space it takes up. view.style.flex = "1"; // use "none" to only take up space required to fit subviews

Using CSS

You can control Styling and Layout in Code.

// TypeScript const sidebar = document.createElement("div"); sidebar.style.backgroundColor = "whitesmoke"; sidebar.style.width = "150px";

Alternatively, you can move Styling and Layout to your style.css file in VSCode.

In either case, it may be helpful to avoid duplicating code, update once.

And secondly, it is nice to have your UI setting separate from other code.

// TypeScript const sidebar = document.createElement("div"); sidebar.className = "sidebar"; // link to css script, where define background color and width
// style.css .sidebar { width: 150px; backgroundColor: whitesmoke; }
