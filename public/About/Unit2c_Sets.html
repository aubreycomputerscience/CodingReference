Sets

Think of a set as an unordered group of items. It can have no duplicate values.

1. Check to see if item is a member of a group.

2. Use to remove dups.

3. Use to combine sets of data, remove elements from one set, or find which elements shared by two sets.


*Implementation Details*

a. Unlike other programming languages, JavaScript/TypeScript will return items in the order they were added.

b. Because JavaScript/TypeScript does not allow you to put objects in sets, they can be awkward to use.

In TypeScript

A set stores a collection of unique items. The same item cannot appear more than once.

const animals = new Set(["cat", "dog", "monkey"]); animals.add("cat"); // If we try to add "cat" again, the set remains unchanged Sets are useful when we need to know whether an item is present. For example, we might use a set to store: - Usernames that have already been selected. - Students who are absent. - Items collected by a player. - Words that appear in a document.

Creating a Set

const animals = new Set(); // A set of strings.

Creating a Set from an Array

const animals = new Set(["cat", "dog", "monkey"]); // We are passing in an array.

Creating an Array from a Set

const animalArray = [...animals]; // use the spread operator to convert a set into an array

Quick Reference

mySet.add("dog") // Add an item mySet.has("cat") // Check whether an item is present mySet.delete("dog") // Delete one item mySet.clear() // Delete every item mySet.size // Find the number of items

Sets Operations (our primary use case)

Union: Combine elements from two sets. That is, SetC = SetA + SetB.

Intersection: Find elements shared by two sets.

Difference: Remove elements from a set. That is, subtract SetA from SetB.

In Code

const heroesWithCapes = new Set([ "Batman", "Superman", "Thor" ]); const heroesWhoCanFly = new Set([ "Superman", "Thor", "Iron Man" ]);

Union: contains every item found in either set.

const heroesWithCapesOrFlight = heroesWithCapes.union(heroesWhoCanFly); // Batman, Superman, Thor // plus Superman, Thor, Iron Man // equals Batman, Superman, Thor, Iron Man // *Items that appear in both sets are included only once.

Intersection: contains only the items found in both sets.

const flyingHeroesWithCapes = heroesWithCapes.intersection(heroesWhoCanFly); // Batman, Superman, Thor // and Superman, Thor, Iron Man // have Superman and Thor in common

Difference: contains the items found in the first set but not in the second.

const heroesWithCapesWhoCannotFly = heroesWithCapes.difference(heroesWhoCanFly); // Batman, Superman, Thor // minus Superman, Thor, Iron Man // equals Batman The order matters when finding the difference: const flyingHeroesWithoutCapes = heroesWhoCanFly.difference(heroesWithCapes); // Superman, Thor, Iron Man // minus Batman, Superman, Thor // equals Iron Man

Data Structures: In Review

In review, our basic collection types have different purposes: - An array stores an ordered list of items and can contain duplicates. - A dictionary connects keys with values. - A set stores unique items and provides a quick way to check whether an item is present.
