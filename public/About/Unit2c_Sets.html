And so on and so forth. Lesson 5.1: What Is a Function? As a program becomes larger, it becomes difficult to understand everything at once. We can make the program easier to work with by dividing it into smaller pieces of code called functions. Each function should perform a small, clearly defined task. For example, a game might contain separate functions for calculating damage, healing a character, moving an enemy, and checking whether the player has won. A function gives a name to a piece of code: function healCharacter() { // Restore the character's health. } The name healCharacter tells us what the function does. In this way, a good function name acts like a topic sentence. It allows us to understand the purpose of the code without immediately reading every instruction inside it. Creating a function is called defining a function. The code inside the function does not run until we call it: healCharacter(); The parentheses tell the program to run the function. Functions help us: divide a large program into smaller tasks give meaningful names to sections of code reuse code without writing it again hide unnecessary details make programs easier to read, test, and change A function attached to an object or class is called a method. Functions and methods work in similar ways, but a method belongs to a particular object or class. Lesson 5.2: Using Functions Parameters and Arguments A function can receive information through parameters. function greetPerson(name: string) { const greeting = "Hello, " + name; } The parameter name is a variable that belongs to the function. It allows the function to work with different names. When we call the function, we provide a value: greetPerson("Maria"); greetPerson("Devon"); The value passed into a function is called an argument. In this example: function greetPerson(name: string) { const greeting = "Hello, " + name; } greetPerson("Maria"); name is the parameter. "Maria" is the argument. A function can have more than one parameter: function calculateDamage(attack: number, defense: number) { const damage = attack - defense; } The arguments are matched with the parameters according to their position: calculateDamage(30, 10); Here, 30 becomes attack and 10 becomes defense. Clear parameter names make function calls easier to understand: const playerAttack = 30; const enemyDefense = 10; calculateDamage(playerAttack, enemyDefense); This is often clearer than passing several unexplained numbers directly into the function. Return Values A function can send a result back to the code that called it. This is called a return value. function calculateDamage(attack: number, defense: number): number { return attack - defense; } The type after the parentheses states what kind of value the function returns: : number We can store the returned value in a variable: const damage = calculateDamage(30, 10); The function receives 30 and 10, calculates the result, and returns 20. The value 20 is then stored in damage. A returned value can also be used directly: const remainingHitPoints = hitPoints - calculateDamage(attack, defense); When a function reaches return, it immediately stops running: function calculateDamage(attack: number, defense: number): number { if (defense >= attack) { return 0; } return attack - defense; } If defense is greater than or equal to attack, the function returns 0 and skips the remaining code. A function that does not return a value can use the return type void: function healCharacter(character: Character): void { character.heal(); } TypeScript can usually determine the return type without our writing it. However, explicitly including it can make the purpose of a function clearer.

Sets

Store data in set.

Think of a set as an unordered group of items. It can have no duplicate values.

1. Use for quick lookup.

2. Use to remove dups.

3. Use to combine sets of data, remove elements from one set, or find which elements shared by two sets.


*Implementation Detail*

Unlike other programming languages, JavaScript/TypeScript will return items in the order they were added.

A set stores a collection of unique items. The same item cannot appear more than once.

const animals = new Set(["cat", "dog", "monkey"]); If we try to add "cat" again, the set remains unchanged: animals.add("cat"); // animals still contains: // "cat", "dog", "monkey" Sets are useful when we mainly need to know whether an item is present. For example, we might use a set to store: usernames that have already been selected students who are absent items collected by a player words that appear in a document In review, our basic collection types have different purposes: An array stores an ordered list of items and can contain duplicates. A dictionary connects keys with values. A set stores unique items and provides a quick way to check whether an item is present.

Creating a Set

const animals = new Set(); // A set of strings. // or const animals = new Set(["cat", "dog", "monkey"]); // We are passing in an array.

Quick Reference

mySet.add("dog") Add an item mySet.has("cat") Check whether an item is present mySet.delete("dog") Delete one item mySet.clear() Delete every item mySet.size Find the number of items
