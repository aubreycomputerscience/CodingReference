LESSON: GLOBAL VARIABLES (AND SCOPE)

export function startApp() { let xPosition = 0; // When startApp() is run, these variables will be created. let yPosition = 0; // When startApp() ends, everything is deleted. }

A function performs a task, moving line by line, down through the code, and then deletes everything within when completed. In Computer Science, we say that the variable exists within a "local scope" and after this function (code chunk) variables are “deallocated.”

We can solve this problem by creating/storing/declaring the variables outside of our function.

// SHARED/PERMANENT DATA (also known as GLOBAL VARIALBES) let xPosition = 0; let yPosition = 0; export function startApp() { // now we can use xPosition and yPosition in our function }
