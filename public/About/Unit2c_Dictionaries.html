Dictionaries: Looking Up Data

Store information in a dictionary.

Look it up!

The Oxford dictionary stores an entry for each word.

cat: an animal that goes meow dog: an animal that goes woof

In computer science, we can store information in a similar way.

The keyword "cat" is called a key, and the information is called a value. Thus, a dictionary (also known as a Map) is a collection of key-value pairs, to put it technically.

const grades = new Map(); grades.set("Maria", 95);

Look Up Grades

const mariaGrade = grades.get("Maria"); if (mariaGrade !== undefined) { // Use mariaGrade. }

INSTRUCTIONS - See if the Students Know how to use them. He are the notes from our textbook. The Oxford Dictionary contains a list of words and their corresponding definitions. This allows us to look up information with ease. In computer science, we can store information in a similar way. For the keyword "cat", we can store the definition "an animal that goes meow." cat: an animal that goes meow dog: an animal that goes woof The keyword "cat" is called a key, and the information is called a value. Thus, a dictionary is a collection of key-value pairs, to put it technically. It should be noted that the keyword does not need to be text. A dictionary gives us quick access to stored information. It also allows us to add, delete, or update entries with ease. In TypeScript, we can create a dictionary using a Map. Dictionaries are useful when we frequently need to look up information using a known key. For example: Student name → grade State code → state name User ID → user information Word → definition If we need to store information in an ordered list, an array is a better choice. A dictionary provides a quick lookup by key. With an array, we may have to search through the items one by one until we find the one we need. This can require a great deal of work if the array contains millions of items. Think of a dictionary as an unordered list of keys and values. In JavaScript, Map guarantees that entries will appear in insertion order when we loop through them, but dictionaries in other programming languages, generally, do not. Lesson 2.2: Using a Dictionary CREATING A MAP We can create an empty Map and state the types used for its keys and values: const grades = new Map(); Read this as: A Map with string keys and number values. We can also create a Map that already contains entries: const grades = new Map([ ["Maria", 95], ["Devon", 87] ]); Each entry contains a key followed by the value saved for that key. Key: "Maria" Value: 95 const grades = new Map(); grades.set("Maria", 95); grades.set("Devon", 87); We can later use the key "Maria" to retrieve the value 95. If the key already exists, set() replaces the old value: grades.set("Maria", 99); The value for the key "Maria" is now 99. A Map can contain only one value for each key. LOOKING UP A VALUE The get() method retrieves the value for a key: const mariaGrade = grades.get("Maria"); // 99 If the key does not exist, get() returns undefined: const samGrade = grades.get("Sam"); // undefined We can check the result before using it: const mariaGrade = grades.get("Maria"); if (mariaGrade !== undefined) { // Use mariaGrade. } We can also use has() when we only need to know whether the key exists: if (grades.has("Maria")) { // The dictionary contains an entry for Maria. } The difference is simple: get() retrieves the value for a key. has() tells us whether the key exists. DELETING ENTRIES The delete() method removes the entry for a key: grades.delete("Devon"); The clear() method removes every entry: grades.clear(); COUNTING ENTRIES The size property tells us how many entries are in a Map: const numberOfStudents = grades.size; Like an arrays length, size is a property and does not use parentheses. WORKING THROUGH A MAP We can use a for...of loop to work through every key and value: for (const [name, grade] of grades) { // Use name and grade. } Each time through the loop, the first variable contains the key and the second contains its value. We can also work through only the keys: for (const name of grades.keys()) { // Use name. } Or only the values: for (const grade of grades.values()) { // Use grade. }
