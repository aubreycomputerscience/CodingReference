Dictionaries: Looking Up Data

Store information in a dictionary.

Look it up!

The Oxford dictionary stores an entry for each word.

cat: an animal that goes meow dog: an animal that goes woof

In computer science, we can store information in a similar way.

The keyword "cat" is called a key, and the information is called a value. Thus, a dictionary (also known as a Map) is a collection of key-value pairs, to put it technically.

const grades = new Map<>(); grades.set("Maria", 95);

Look Up Grades

const mariaGrade = grades.get("Maria"); if (mariaGrade !== undefined) { // Use mariaGrade. }

Quick Reference

Code Description
myMap.set(key, value) Add or update dictionary with value.
myMap.get(key) Retrieve the value for a key
myMap.has(key) Check whether a key exists
myMap.delete(key) Delete one entry
myMap.clear() Delete every entry
myMap.size Find the number of entries
myMap.keys() Work through the keys
myMap.values() Work through the values

The Oxford Dictionary contains a list of words and their corresponding definitions. This allows us to look up information with ease. In computer science, we can store information in a similar way. For the keyword "cat", we can store the definition "an animal that goes meow." cat: an animal that goes meow dog: an animal that goes woof The keyword "cat" is called a key, and the information is called a value. Thus, a dictionary is a collection of key-value pairs, to put it technically. It should be noted that the keyword does not need to be text. A dictionary gives us quick access to stored information. It also allows us to add, delete, or update entries with ease. In TypeScript, we can create a dictionary using a Map. Dictionaries are useful when we frequently need to look up information using a known key. For example: Student name → grade State code → state name User ID → user information Word → definition If we need to store information in an ordered list, an array is a better choice. A dictionary provides a quick lookup by key. With an array, we may have to search through the items one by one until we find the one we need. This can require a great deal of work if the array contains millions of items. Think of a dictionary as an unordered list of keys and values. In JavaScript, Map guarantees that entries will appear in insertion order when we loop through them, but dictionaries in other programming languages, generally, do not. Lesson 2.2: Using a Dictionary CREATING A MAP We can create an empty Map and state the types used for its keys and values: const grades = new Map(); Read this as: A Map with string keys and number values. We can also create a Map that already contains entries: const grades = new Map([ ["Maria", 95], ["Devon", 87] ]); Each entry contains a key followed by the value saved for that key. Key: "Maria" Value: 95 const grades = new Map(); grades.set("Maria", 95); grades.set("Devon", 87); We can later use the key "Maria" to retrieve the value 95. If the key already exists, set() replaces the old value: grades.set("Maria", 99); The value for the key "Maria" is now 99. A Map can contain only one value for each key. LOOKING UP A VALUE The get() method retrieves the value for a key: const mariaGrade = grades.get("Maria"); // 99 If the key does not exist, get() returns undefined: const samGrade = grades.get("Sam"); // undefined We can check the result before using it: const mariaGrade = grades.get("Maria"); if (mariaGrade !== undefined) { // Use mariaGrade. } We can also use has() when we only need to know whether the key exists: if (grades.has("Maria")) { // The dictionary contains an entry for Maria. } The difference is simple: get() retrieves the value for a key. has() tells us whether the key exists. DELETING ENTRIES The delete() method removes the entry for a key: grades.delete("Devon"); The clear() method removes every entry: grades.clear(); COUNTING ENTRIES The size property tells us how many entries are in a Map: const numberOfStudents = grades.size; Like an arrays length, size is a property and does not use parentheses. WORKING THROUGH A MAP We can use a for...of loop to work through every key and value: for (const [name, grade] of grades) { // Use name and grade. } Each time through the loop, the first variable contains the key and the second contains its value. We can also work through only the keys: for (const name of grades.keys()) { // Use name. } Or only the values: for (const grade of grades.values()) { // Use grade. }

Chapter 5: Functions Lesson 5.1: What Is a Function? As a program becomes larger, it becomes difficult to understand everything at once. We can make the program easier to work with by dividing it into smaller pieces of code called functions. Each function should perform a small, clearly defined task. For example, a game might contain separate functions for calculating damage, healing a character, moving an enemy, and checking whether the player has won. A function gives a name to a piece of code: function healCharacter() { // Restore the character's health. } The name healCharacter tells us what the function does. In this way, a good function name acts like a topic sentence. It allows us to understand the purpose of the code without immediately reading every instruction inside it. Creating a function is called defining a function. The code inside the function does not run until we call it: healCharacter(); The parentheses tell the program to run the function. Functions help us: divide a large program into smaller tasks give meaningful names to sections of code reuse code without writing it again hide unnecessary details make programs easier to read, test, and change A function attached to an object or class is called a method. Functions and methods work in similar ways, but a method belongs to a particular object or class. Lesson 5.2: Using Functions Parameters and Arguments A function can receive information through parameters. function greetPerson(name: string) { const greeting = "Hello, " + name; } The parameter name is a variable that belongs to the function. It allows the function to work with different names. When we call the function, we provide a value: greetPerson("Maria"); greetPerson("Devon"); The value passed into a function is called an argument. In this example: function greetPerson(name: string) { const greeting = "Hello, " + name; } greetPerson("Maria"); name is the parameter. "Maria" is the argument. A function can have more than one parameter: function calculateDamage(attack: number, defense: number) { const damage = attack - defense; } The arguments are matched with the parameters according to their position: calculateDamage(30, 10); Here, 30 becomes attack and 10 becomes defense. Clear parameter names make function calls easier to understand: const playerAttack = 30; const enemyDefense = 10; calculateDamage(playerAttack, enemyDefense); This is often clearer than passing several unexplained numbers directly into the function. Return Values A function can send a result back to the code that called it. This is called a return value. function calculateDamage(attack: number, defense: number): number { return attack - defense; } The type after the parentheses states what kind of value the function returns: : number We can store the returned value in a variable: const damage = calculateDamage(30, 10); The function receives 30 and 10, calculates the result, and returns 20. The value 20 is then stored in damage. A returned value can also be used directly: const remainingHitPoints = hitPoints - calculateDamage(attack, defense); When a function reaches return, it immediately stops running: function calculateDamage(attack: number, defense: number): number { if (defense >= attack) { return 0; } return attack - defense; } If defense is greater than or equal to attack, the function returns 0 and skips the remaining code. A function that does not return a value can use the return type void: function healCharacter(character: Character): void { character.heal(); } TypeScript can usually determine the return type without our writing it. However, explicitly including it can make the purpose of a function clearer. Optional Parameters and Values Sometimes a parameter does not need to be provided. We can place a question mark after its name: function greetPerson(name: string, title?: string) { // Use name and title. } The function can now be called with or without a title: greetPerson("Maria"); greetPerson("Maria", "Captain"); Inside the function, title may contain a string or it may contain undefined. We can write this more explicitly using a union type: function greetPerson(name: string, title: string | undefined) { // Use name and title. } The vertical line means or. Read this as: title can contain a string or undefined. There is an important difference between these two forms. The question mark allows us to leave out the argument: greetPerson("Maria"); With string | undefined, the argument is still required, although its value may be undefined: greetPerson("Maria", undefined); Union types can also describe other optional values: function findCharacter(name: string): Character | undefined { // Return a Character if one is found. // Otherwise, return undefined. } The function may return a Character, or it may return undefined if no matching character exists.
