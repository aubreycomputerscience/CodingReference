Dictionaries: Looking Up Data

Store information in a dictionary.

Look it up!

The Oxford dictionary stores an entry for each word.

cat: an animal that goes meow dog: an animal that goes woof

In computer science, we can store information in a similar way.

The keyword "cat" is called a key, and the information is called a value. Thus, a dictionary (also known as a Map) is a collection of key-value pairs, to put it technically.

const grades = new Map(); grades.set("Maria", 95);

Look Up Grades

const mariaGrade = grades.get("Maria"); if (mariaGrade !== undefined) { // Use mariaGrade. }

Quick Reference

Code Description
myMap.get(key) Retrieve the value for a key
myMap.has(key) Check whether a key exists
myMap.delete(key) Delete one entry
myMap.clear() Delete every entry
myMap.size Find the number of entries
myMap.keys() Work through the keys
myMap.values() Work through the values
