PRINCIPLES OF INFORMATION TECHNOLOGY

Principles of Information Technology introduces students to the major areas of IT, including computer hardware, networking, cybersecurity, software and web development, data, artificial intelligence, and technical support. The course combines Texas state standards with practical projects that emphasize understanding how technology works and how it is used in the workplace. Students also explore emerging technologies, analyze data, complete an integrated IT project, and investigate careers, education, certifications, and other pathways into the technology industry.

PREVIEW

I. Preview of Careers & Technology Trends

  1. Identify major career areas within information technology, including software development, technical support, networking, cybersecurity, data, cloud computing, and related fields. <PREV-1>
  2. Discuss how automation, AI, and emerging technologies may change jobs and workplace responsibilities. <PREV-2>

FOUNDATIONS

II. Computers & Technical Support

A. Computer Hardware

  1. Understand how the major components of a computer work together. Explain at a high level what the CPU, GPU, NPU, memory, storage, input/output devices, and other major components do and how they perform their work—for example, a CPU executes general-purpose instructions, while a GPU performs many mathematical operations in parallel. <HW-1>
  2. Explain why particular hardware may be better suited for tasks such as everyday computing, gaming, media production, or AI. <HW-2>

B. Operating Systems & Software

  1. Explain the basic role of an operating system in running applications, managing hardware, and organizing files. <OS-1>
  2. Distinguish between operating systems, applications, utilities, and device drivers. (Compare open-source and proprietary software.) <OS-2>
  3. Manage files and folders, recognize common file types, and use basic file-security features. <OS-3>
  4. Identify common system-management tools and explain what they are used for. <OS-4>

C. Technical Support

  1. Use reference tools and documentation to troubleshoot basic computer or network problems. <SUP-1>
  2. Identify, connect, and use common peripherals and connections, using documentation when needed. <SUP-2>
  3. Explain the purpose of common system-management tools. <SUP-3>
  4. Explain basic approaches for detecting, quarantining, and removing viruses or other malware. <SUP-4>
  5. Understand basic workplace health, safety, and first-aid practices. <SUP-5>

III. Networks, Cloud & Cybersecurity

A. Networks & the Internet

  1. Explain how computers and other devices communicate across local networks and the Internet. <NET-1>
  2. Identify the basic roles of routers, switches, servers, wireless access points, common network connections, and operating systems used to manage network resources. <NET-2>
  3. Distinguish among common network types and technologies, including LANs, WANs, Ethernet, Wi-Fi, and peer-to-peer networks. <NET-3>
  4. Explain the basic roles of common Internet protocols and services, including DNS, HTTPS, and email. <NET-4>

B. Cloud Computing

  1. Explain what is meant by cloud computing and distinguish cloud services from software or data stored only on a local device. <CLOUD-1>
  2. Identify common cloud services such as remote storage, databases, hosted applications, authentication, and computing resources. <CLOUD-2>
  3. Explain why organizations may use cloud services and discuss basic tradeoffs involving cost, reliability, control, security, and privacy. <CLOUD-3>

C. Cybersecurity

  1. Explain the roles of passwords, authentication, encryption, permissions, and software updates in protecting systems and information. <SEC-1>
  2. Identify common cybersecurity threats, including phishing, malware, weak passwords, hacking, identity theft, and data breaches. <SEC-2>
  3. Recognize common social-engineering techniques and explain why people are often an important part of computer security. <SEC-3>
  4. Apply basic cybersecurity practices when using computers, online accounts, and shared information. <SEC-4>

BUILDING

IV. Software & Web Development

A. Coding

  1. Write a simple program. Use numbers, text, Boolean values, conditionals ("selection"), and loops ("iteration"). <CODE-1>
  2. Create and represent algorithms. Describe a process for solving a problem using code, written steps, flowcharts, or similar visual tools. (TEKS terminology includes "linear" for instructions performed in sequence and "iterative" for repetition.) <CODE-2>
  3. Explain how programming languages are used and executed. Briefly compare several common languages and their uses, and explain the basic roles of compilers and interpreters. (Languages may distinguish data such as strings, numbers, characters, integers, and dates differently.) <CODE-3>

B. Web Development

  1. Create a webpage. Use HTML to add text, images, and links. <WEB-1>
  2. Understand how webpages are built. Explain the basic roles of HTML, CSS, browsers, and web servers. (Use hexadecimal values to represent colors.) <WEB-2>
  3. Understand the basic architecture of modern websites. Explain at a high level how a website or application may combine a user interface, client-side code, servers, databases, APIs, and cloud services. <WEB-3>
  4. Apply basic principles of layout, readability, navigation, and visual design when creating digital content. (Design terminology includes typeface, color, shape, texture, space, form, unity, harmony, balance, scale, and contrast.) <WEB-4>

ANALYZING

V. Data & Information

A. Spreadsheets

  1. Organize information in a spreadsheet using rows, columns, labels, and appropriate data formats. <SHEET-1>
  2. Use formulas and common functions to calculate and summarize information. (Include nested IF statements and subtotals.) <SHEET-2>
  3. Use sorting, filtering, conditional formatting, lookup tools, and cell protection to answer questions about a dataset. <SHEET-3>
  4. Create charts and other visual representations that communicate information clearly. <SHEET-4>
  5. Import or export structured data using common formats such as CSV. <SHEET-5>
  6. Use spreadsheets to solve authentic problems such as comparing costs, analyzing survey results, tracking projects, or examining career information. <SHEET-6>

Suggested Project — Stock Analysis: Import historical stock data, calculate changes, returns, and averages, sort and filter companies, use formulas and lookup functions, and graph prices or other measures.

B. Databases

  1. Explain why databases are used when information becomes too large, interconnected, or complex for a simple spreadsheet. <DB-1>
  2. Identify fields, records, tables, keys, and relationships in a relational database. <DB-2>
  3. Use simple queries to find information that meets one or more conditions. <DB-3>
  4. Explain at a high level how SQL is used to work with relational databases. <DB-4>
  5. Compare relational databases with NoSQL approaches and recognize that different applications may organize data differently. <DB-5>
  6. Explain how databases may be hosted locally or provided as cloud services. <DB-6>

C. Data Analysis

  1. Use data to identify patterns, compare groups, and support conclusions. <DATA-1>
  2. Recognize that correlation does not necessarily demonstrate causation. <DATA-2>
  3. Identify ways that incomplete, biased, poorly collected, or misleadingly presented data can affect conclusions. <DATA-3>
  4. Communicate findings using appropriate tables, charts, written explanations, or presentations. <DATA-4>

VI. Artificial Intelligence

A. How It Works

  1. Give a high-level technical explanation of how an AI system works. Explain how an AI system is trained and then uses what it learned to make inferences. <AI-1>
  2. Explain how training data shapes what an AI system learns. AI systems identify patterns in the examples they are given, so the quality and bias of the data matter. <AI-2>

B. Uses

  1. Identify the broad kinds of tasks AI systems perform. They can classify information, recognize patterns, and make predictions. <AI-3>
  2. Examine how AI is used in many different real-world settings. Students will examine examples from business, creative work, management, everyday life, and entertainment. <AI-4>
  3. Explain AI's important limitations. Results may be biased, misleading, or incorrect, and human judgment is still necessary. <AI-5>

IMPLEMENTING

VII. Integrated IT Project

A. Project Planning

  1. Identify a real or realistic IT problem, organization, or scenario and develop a plan for addressing it. Follow the basic project-management process (initiating, planning, executing, monitoring/controlling, and closing). <PLAN-1>
  2. Find and evaluate information online. Use effective search strategies and evaluate sources for accuracy, relevance, and validity. (Identify the basic components of a URL and use keywords and Boolean search when appropriate.) <PLAN-2>
  3. Break a larger project into manageable tasks and establish milestones, responsibilities, and deadlines. <PLAN-3>
  4. Use planning techniques such as storyboards, diagrams, outlines, or project-management tools where appropriate. <PLAN-4>
  5. Create a project proposal or other appropriate professional document using a word processor. <PLAN-5>
  6. Communicate progress, problems, and decisions throughout the project using appropriate electronic communication. <PLAN-6>
  7. Give and respond constructively to feedback, and revise the project in response to testing, feedback, or changing requirements. <PLAN-7>
  8. Demonstrate professional workplace skills throughout the project. Apply teamwork, communication, time management, reliability, responsibility, appropriate workplace conduct, respect for others, and basic conflict-resolution practices. <PLAN-8>

B. Google Sites Project

  1. Create a Google Site that serves as the central location for an integrated IT project. <SITE-1>
  2. Organize the site into logical pages and incorporate appropriate text, images, charts, spreadsheets, documents, links, and other supporting materials. <SITE-2>
  3. Learn unfamiliar software independently using built-in help, documentation, online resources, experimentation, or AI when appropriate. (This provides real-world experience and prepares students for workplaces where unfamiliar software must often be learned without step-by-step instruction.) <SITE-3>
  4. Present the project using Google Slides or PowerPoint. Incorporate links, audio, graphics, and other media where appropriate, and follow appropriate copyright, licensing, citation, privacy, and security practices. (Include trademarks, patents, plagiarism, online piracy, data vandalism, and consequences of violating intellectual-property laws.) <SITE-4>
  5. Reflect on the project process, including what worked, what did not, and what could be improved. <SITE-5>

CAREERS

VIII. Career & Portfolio Project

A. Career Exploration

  1. Research specific IT careers, including typical responsibilities, education, certifications, working conditions, compensation, management roles, and opportunities for entrepreneurship. <CAREER-1>
  2. Compare different pathways into IT careers, including university programs, certifications, technical training, internships, and independent learning. <CAREER-2>

B. Résumé & Portfolio

  1. Create a professional résumé using a word processor. (Use appropriate pagination, white space, tabs, and font style, size, and color.) <PORT-1>
  2. Build or begin a portfolio that demonstrates projects, skills, and experience and can be developed throughout later technology courses. <PORT-2>
