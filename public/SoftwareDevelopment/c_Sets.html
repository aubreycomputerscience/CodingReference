Chapter 3: Sets

Lesson 3.1: What Is a Set?

A set stores a collection of unique items. The same item cannot appear more than once. 

const animals = new Set(["cat", "dog", "monkey"]);

If we try to add "cat" again, the set remains unchanged: 

animals.add("cat");

// animals still contains:
// "cat", "dog", "monkey"

Sets are useful when we mainly need to know whether an item is present. For example, we might use a set to store:

  • usernames that have already been selected
  • students who are absent
  • items collected by a player
  • words that appear in a document

In review, our basic collection types have different purposes:

  • An array stores an ordered list of items and can contain duplicates.
  • A dictionary connects keys with values.
  • A set stores unique items and provides a quick way to check whether an item is present.

Lesson 3.2: How a Set May Be Implemented

A set can be implemented using a dictionary. Each set item is stored as a dictionary key, while its corresponding value is an unused placeholder. 

Key: "cat"
Value: unused

The set can then use the dictionary’s quick key lookup to determine whether "cat" is present.

This is a common way to implement a set, although JavaScript does not specify exactly how Set must work internally.

Lesson 3.3: Using a Set

Working with Sets

We can create an empty set and state what type of information it will contain: 

const animals = new Set<string>();

Read this as:

A set of strings.

We can also create a set that already contains items:

const animals = new Set(["cat", "dog", "monkey"]);

Quick Reference

mySet.add(value) Add an item
mySet.has(value) Check whether an item is present
mySet.delete(value) Delete one item
mySet.clear() Delete every item
mySet.size Find the number of items

The add() method adds an item to a set:

animals.add("tiger");

Adding an item that is already present does nothing:

animals.add("cat");

The has() method checks whether an item is in the set: 

if (animals.has("cat")) {
    // The set contains "cat".
}

The delete() method removes an item:

animals.delete("dog");

The clear() method removes every item:

animals.clear();

The size property tells us how many items are in the set: 

const numberOfAnimals = animals.size;

Like an array’s length, size is a property and does not use parentheses.

Working Through a Set and Converting It into an Array

We can use a for...of loop to work through every item: 

for (const animal of animals) {
    // Use animal.
}

JavaScript works through the items in the order in which they were added. However, position is not the main purpose of a set. If order and indexes are important, an array is usually a better choice.

We can use the spread operator to convert a set into an array: 

const animalArray = [...animals];

This also provides a quick way to remove duplicate values from an array: 

const names = ["Maria", "Devon", "Maria", "Sam"];

const uniqueNames = [...new Set(names)];

// uniqueNames contains:
// ["Maria", "Devon", "Sam"]

There is one important detail when storing objects in a set. Objects are compared by reference rather than by their contents. 

const firstDog = { name: "Spot" };
const secondDog = { name: "Spot" };

const dogs = new Set([firstDog, secondDog]);

Although the two objects contain the same information, they are separate objects stored at different locations in memory. Therefore, the set contains two items.

Lesson 3.4: Set Operations

Set operations allow us to compare or combine groups of items.

The three basic set operations are:

  • A union is like addition. It combines the items from two sets.
  • An intersection finds the items that the sets have in common.
  • A difference is like subtraction. It removes the items in one set from another.

Suppose we have one set containing superheroes who wear capes and another containing superheroes who can fly: 

const heroesWithCapes = new Set([
    "Batman",
    "Superman",
    "Thor"
]);

const heroesWhoCanFly = new Set([
    "Superman",
    "Thor",
    "Iron Man"
]);

Union

A union contains every item found in either set:

const heroesWithCapesOrFlight =
    heroesWithCapes.union(heroesWhoCanFly);

// Batman, Superman, Thor
// plus Superman, Thor, Iron Man
// equals Batman, Superman, Thor, Iron Man

Items that appear in both sets are included only once.

Intersection

An intersection contains only the items found in both sets: 

const flyingHeroesWithCapes =
    heroesWithCapes.intersection(heroesWhoCanFly);

// Batman, Superman, Thor
// and Superman, Thor, Iron Man
// have Superman and Thor in common

Difference

A difference contains the items found in the first set but not in the second: 

const heroesWithCapesWhoCannotFly =
    heroesWithCapes.difference(heroesWhoCanFly);

// Batman, Superman, Thor
// minus Superman, Thor, Iron Man
// equals Batman

The order matters when finding the difference:

const flyingHeroesWithoutCapes =
    heroesWhoCanFly.difference(heroesWithCapes);

// Superman, Thor, Iron Man
// minus Batman, Superman, Thor
// equals Iron Man

These operations create new sets. They do not change the original sets.
