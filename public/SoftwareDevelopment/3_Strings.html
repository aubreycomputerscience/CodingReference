Chapter 3: Strings

Lesson 3.1: Creating and Combining Strings

A string is text stored by a program. We create a string by placing text inside quotation marks. 

const animal = "cat";
const greeting = "Hello";
const playerName = "Jon Snow";

Quotation marks tell TypeScript where the text begins and ends. The quotation marks are not part of the text itself.

We can use either double quotation marks or single quotation marks: 

const firstAnimal = "cat";
const secondAnimal = 'dog';

Both create strings. In this class, we will normally use double quotation marks so that our code remains consistent.

We can combine strings using the + symbol:

const firstName = "Jon";
const lastName = "Snow";

const fullName = firstName + lastName;

This creates the string:

JonSnow

The computer does not automatically insert a space. If we want a space, we must include it ourselves: 

const fullName = firstName + " " + lastName;

Now fullName contains:

Jon Snow

This is called string concatenation. Concatenation means joining strings together.

We can combine text and variables:

const animal = "cat";
const sentence = "My favorite animal is a " + animal + ".";

The variable sentence now contains:

My favorite animal is a cat.

Later, you may also see strings written using backticks:

const sentence = `My favorite animal is a ${animal}.`;

This is called a template string. It provides another way to insert values into text. In this class, we will usually begin by combining strings with the + symbol because it makes each part of the operation easy to see.

Lesson 3.2: Working with Strings

Strings come with useful tools that allow us to examine or work with text.

A property stores information about a string. For example, the length property tells us how many characters are in it: 

const animal = "tiger";
const numberOfCharacters = animal.length;

The value of numberOfCharacters is 5.

Spaces and punctuation also count as characters:

const message = "Hello!";
const messageLength = message.length;

The value of messageLength is 6.

We can also ask TypeScript to perform an action using a string. For example: 

const animal = "tiger";
const largeAnimal = animal.toUpperCase();

The expression

animal.toUpperCase()

asks TypeScript to create an uppercase version of the string stored in animal.

A function attached to a value in this way is called a method. We use a period after the variable name, followed by the method name and parentheses. 

variable.method()

The variable largeAnimal contains:

TIGER

The original string has not changed. animal still contains "tiger". The toUpperCase() method produced a new string, which we stored in largeAnimal.

The toLowerCase() method produces a lowercase version of a string: 

const message = "HELLO";
const quietMessage = message.toLowerCase();

The variable quietMessage contains "hello".

The includes() method checks whether a string contains particular text: 

const sentence = "The tiger is sleeping.";
const containsTiger = sentence.includes("tiger");

The variable containsTiger contains true.

const containsLion = sentence.includes("lion");

The variable containsLion contains false.

The search is sensitive to capitalization:

const containsUppercaseTiger = sentence.includes("Tiger");

This contains false because "Tiger" and "tiger" are not written the same way.

Some other useful string methods include:

const message = "  Hello, Jon!  ";

const trimmedMessage = message.trim();
const replacedMessage = message.replace("Jon", "Sam");

The trim() method produces a new string without spaces at the beginning or end.

The replace() method produces a new string with one piece of text replaced by another.

Strings cannot be changed after they are created. Methods such as toUpperCase(), trim(), and replace() produce new strings rather than changing the original string. 

const originalMessage = "hello";
const newMessage = originalMessage.toUpperCase();

After this code runs:

originalMessage: "hello"
newMessage:      "HELLO"

This is why we usually assign the result of a string method to a variable or constant.
