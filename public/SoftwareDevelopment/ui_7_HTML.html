5: HTML QUICK REFERENCE

HTML defines the elements that begin on a webpage. In this class, we will usually create interface elements with TypeScript, but students should still be able to read an HTML file, make simple changes, and understand how HTML connects to CSS and TypeScript.

Lesson 5.1: Basic HTML Structure

A basic HTML page looks like this:

<!doctype html>
<html>
    <head>
        <title>My App</title>
    </head>

    <body>
        <h1>My App</h1>
        <p>Welcome to my webpage.</p>
    </body>
</html>

The html element contains the entire webpage. The head stores information about the page, while the body contains the elements that appear on the screen.

The title appears in the browser tab.

Vite creates most of this structure for us, so we will not need to rewrite it for every project. However, we should be able to recognize the main parts of the file.

Lesson 5.2: HTML Elements

Most HTML elements use an opening tag and a closing tag:

<p>Hello!</p>

The opening tag begins the element:

<p>

The closing tag ends it:

</p>

The text or other elements placed between the tags become the contents of the element.

Common Elements

Purpose HTML
Main heading <h1>My App</h1>
Section heading <h2>Introduction</h2>
Display text <p>Hello!</p>
General section or box <div></div>
Display an image <img src="cat.jpg">
Create a button <button>Submit</button>
Get text input <input type="text">

Some elements, such as img and input, do not contain text or other elements. They therefore do not need a separate closing tag.

HTML elements can also be placed inside other elements:

<div>
    <h2>Welcome</h2>
    <p>This text is inside the div.</p>
</div>

The div contains the heading and paragraph.

Lesson 5.3: Attributes

Attributes add information or settings to an HTML element. They are written inside the opening tag. 

<p id="welcomeMessage" class="important-message">
    Welcome
</p>

In this example, the paragraph has an id and a CSS class.

Attribute Purpose
id Connect a particular element to TypeScript
class Connect an element to CSS styling
src Give the source of an image
href Give the destination of a link
type Set the kind of input

For example:

<img src="cat.jpg">

<input type="email">

<p id="welcomeMessage">Welcome</p>

The src attribute gives the name or location of the image. The type attribute tells the browser what kind of input to create. The id gives us a way to find a particular element in TypeScript. 

const welcomeMessage = document.getElementById("welcomeMessage");

Lesson 5.4: Links

A link allows the user to open another location.

<a href="https://example.com">Visit Example</a>

The a stands for anchor. The href attribute gives the destination.

HTML elements can load or open certain resources directly. An image uses src to load an image file, while a link uses href to open another page or location.

Loading data such as JSON requires TypeScript and will be covered in the networking lesson.

Links Within the Same Page

A hash link can move to another location on the same page.

<a href="#arrays">Go to Arrays</a>

<h2 id="arrays">Arrays</h2>

The link contains #arrays, so the browser looks for an element whose id is arrays.

Hash links are also commonly used in one-page apps. Instead of loading a new webpage, the app can read the hash and decide which content to display.

For example:

<a href="#settings">Settings</a>

The URL now ends with:

#settings

A one-page app can use that value to show the Settings section.

Lesson 5.5: Showing and Hiding Elements

HTML elements include a built-in hidden property.

myElement.hidden = true;  // Hide the element.
myElement.hidden = false; // Show the element.

The element still exists in the webpage, but it is not displayed.

We can also hide elements using a CSS class:

.hidden {
    display: none;
}

Then add or remove that class in TypeScript:

myElement.classList.add("hidden");
myElement.classList.remove("hidden");

Adding the class hides the element. Removing the class shows it again.

The built-in hidden property is convenient when we only need to show or hide one element. A CSS class is useful when several elements should share the same rule or when hiding is part of a larger style.

Lesson 5.6: Custom HTML Elements

HTML includes standard elements such as p, button, and img. We can also create our own reusable HTML elements using TypeScript.

A custom element can package several pieces of an interface into one reusable component. For example, we could create a code viewer, score display, music player, calendar, or custom input control. These reusable interface components are sometimes called widgets.

A code viewer could display our code one line or one section at a time, allowing us to walk through how the program works. Once the custom element exists, we can simply drop it into our HTML wherever we want it to appear: 

<code-viewer>
    const message = "Hello!";
</code-viewer>

Implementation Overview

Custom element names must contain a hyphen so that the browser can distinguish them from standard HTML elements.

Before using the custom element, we register it in TypeScript: 

customElements.define(
    "code-viewer",
    CodeViewer
);

The class extends HTMLElement, giving it the normal behavior of an HTML element: 

export class CodeViewer extends HTMLElement {

    connectedCallback() {
        // Set up the code viewer.
    }
}

When the browser finds <code-viewer> in the HTML, it creates the element and calls connectedCallback(). This gives us a place to set up the widget.

We can also add settings using HTML attributes:

<code-viewer
    mode="fullText"
    add-keyboard-control="false">
    const message = "Hello!";
</code-viewer>

The full implementation is more advanced, but the main idea is simple: a custom element lets us package interface code into a reusable HTML element that we can place anywhere on the page.
