Chapter 2: Dictionaries

Lesson 2.1: What Is a Dictionary?

The Oxford Dictionary contains a list of words and their corresponding definitions. This allows us to look up information with ease.

In computer science, we can store information in a similar way. For the keyword "cat", we can store the definition "an animal that goes meow." 

cat: an animal that goes meow
dog: an animal that goes woof

The keyword "cat" is called a key, and the information is called a value. Thus, a dictionary is a collection of key-value pairs, to put it technically. It should be noted that the keyword does not need to be text.

A dictionary gives us quick access to stored information. It also allows us to add, delete, or update entries with ease. In TypeScript, we can create a dictionary using a Map.

Dictionaries are useful when we frequently need to look up information using a known key. For example: 

Student name → grade
State code   → state name
User ID      → user information
Word         → definition

If we need to store information in an ordered list, an array is a better choice.

A dictionary provides a quick lookup by key. With an array, we may have to search through the items one by one until we find the one we need. This can require a great deal of work if the array contains millions of items.

Think of a dictionary as an unordered list of keys and values. In JavaScript, Map guarantees that entries will appear in insertion order when we loop through them, but dictionaries in other programming languages, generally, do not.

Lesson 2.2: Using a Dictionary

CREATING A MAP

We can create an empty Map and state the types used for its keys and values: 

const grades = new Map<string, number>();

Read this as:

A Map with string keys and number values.

We can also create a Map that already contains entries: 

const grades = new Map([
    ["Maria", 95],
    ["Devon", 87]
]);

Each entry contains a key followed by the value saved for that key. 

Key:   "Maria"
Value: 95

QUICK REFERENCE

Method/Property Purpose
myMap.set(key, value) Add or update a value
myMap.get(key) Retrieve the value for a key
myMap.has(key) Check whether a key exists
myMap.delete(key) Delete one entry
myMap.clear() Delete every entry
myMap.size Find the number of entries
myMap.keys() Work through the keys
myMap.values() Work through the values

ADDING AND UPDATING ENTRIES

The set() method saves a value for a key:

const grades = new Map<string, number>();

grades.set("Maria", 95);
grades.set("Devon", 87);

We can later use the key "Maria" to retrieve the value 95.

If the key already exists, set() replaces the old value: 

grades.set("Maria", 99);

The value for the key "Maria" is now 99. A Map can contain only one value for each key.

LOOKING UP A VALUE

The get() method retrieves the value for a key: 

const mariaGrade = grades.get("Maria"); // 99

If the key does not exist, get() returns undefined: 

const samGrade = grades.get("Sam"); // undefined

We can check the result before using it:

const mariaGrade = grades.get("Maria");

if (mariaGrade !== undefined) {
    // Use mariaGrade.
}

We can also use has() when we only need to know whether the key exists: 

if (grades.has("Maria")) {
    // The dictionary contains an entry for Maria.
}

The difference is simple:

  • get() retrieves the value for a key.
  • has() tells us whether the key exists.

DELETING ENTRIES

The delete() method removes the entry for a key: 

grades.delete("Devon");

The clear() method removes every entry:

grades.clear();

COUNTING ENTRIES

The size property tells us how many entries are in a Map: 

const numberOfStudents = grades.size;

Like an array’s length, size is a property and does not use parentheses.

WORKING THROUGH A MAP

We can use a for...of loop to work through every key and value: 

for (const [name, grade] of grades) {
    // Use name and grade.
}

Each time through the loop, the first variable contains the key and the second contains its value.

We can also work through only the keys:

for (const name of grades.keys()) {
    // Use name.
}

Or only the values:

for (const grade of grades.values()) {
    // Use grade.
}

USING A MAP INSTEAD OF BRACKETS

Programmers coming from some other languages may expect to access dictionary values using brackets: 

grades["Maria"];

JavaScript’s Map does not use bracket syntax for its entries. We must use set() and get(): 

grades.set("Maria", 95);

const mariaGrade = grades.get("Maria");

This syntax is more cumbersome, but it is the syntax required when working with a Map.

Lesson 2.3: How Hash Tables Work

One common way to build a dictionary is to use an array. 

Index:  0    1    2    3    4    5    6    7
Entry:  —    —    —    —    —    —    —    —

The dictionary needs to convert a key, such as "cat", into one of these array indexes. It does this using a hash function.

A hash function processes the characters in a key and produces a number. It uses an equation like one we might encounter in a mathematics class. The equation must always produce the same result for the same key.

For example, a simplified hash function might convert each character into a number, multiply those numbers by selected values, and add the results: 

"cat" → character numbers → equation → 139

The array in our example has only eight positions, so we can use the remainder operator to convert 139 into a valid index: 

139 % 8 → 3

The entry is placed at index 3:

An Array

Index:  0    1    2       3       4    5    6    7
Entry:  —    —    —    cat:meow   —    —    —    —

When we later ask for the value for "cat", the dictionary performs the same calculation and returns to index 3.

It does not need to search through every entry one by one. This provides a quick lookup even when the dictionary contains a very large number of entries.

A real hash function is designed to distribute keys throughout the array rather than placing too many entries at the same indexes.

HASH COLLISIONS

Different keys can sometimes produce the same array index. This is called a hash collision. 

hash("cat") → 3
hash("dog") → 3

There are two common ways to handle this.

With separate chaining, each array position contains a bucket that can hold more than one entry: 

Index 3:
    cat → meow
    dog → woof

With open addressing, the dictionary looks for another available position when the intended position is already occupied.

The implementation details vary, but the basic idea remains:

  1. Convert the key into a number.
  2. Use that number to select an array position.
  3. Handle collisions when multiple keys select the same position.

JavaScript does not require Map to use this exact implementation. Hash tables provide the standard intuition for how dictionaries can perform quick lookups.
