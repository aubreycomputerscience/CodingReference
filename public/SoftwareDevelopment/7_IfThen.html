Chapter 6: Conditionals

Conditional statements tell a program whether or not to run a piece of code. The program checks whether a condition is true and then decides which code to run.

Lesson 6.1: If Statements

An if statement tells the program to run a piece of code only when a condition is true. 

const hitPoints = 20;

if (hitPoints < 30) {
    // Warn the player that health is low.
}

The condition appears inside the parentheses. In this example, the program checks whether hitPoints is less than 30.

If the condition is true, the code inside the braces runs. If it is false, the program skips that code.

COMPARISONS

We can create conditions by comparing values:

score === 100; // Equal to
score !== 100; // Not equal to
score > 100;   // Greater than
score < 100;   // Less than
score >= 100;  // Greater than or equal to
score <= 100;  // Less than or equal to

Use === to check whether two values are equal. A single equal sign, =, assigns a value. 

score = 100;   // Assign 100 to score.
score === 100; // Check whether score equals 100.

BOOLEAN CONDITIONS

A condition can also use a Boolean value directly:

const hasKey = true;

if (hasKey) {
    // Open the door.
}

Because hasKey is true, the code inside the braces runs.

We can combine or reverse Boolean conditions using &&, ||, and !. 

const hasKey = true;
const doorIsLocked = true;

if (hasKey && doorIsLocked) {
    // Unlock the door.
}

&& means and. Both conditions must be true. 

if (hasKey || doorIsOpen) {
    // Allow the player to enter.
}

|| means or. At least one condition must be true. 

if (!doorIsLocked) {
    // Allow the player to enter.
}

! means not. It reverses a Boolean value, changing true to false or false to true.

Lesson 6.2: If, Else If, and Else

Sometimes a program must choose between two possibilities. We can use else to specify what should happen when the if condition is false. 

const hasKey = false;

if (hasKey) {
    // Open the door.
} else {
    // Keep the door locked.
}

If hasKey is true, the first piece of code runs. Otherwise, the code following else runs.

We can add else if when there are more than two possible outcomes. 

const hitPoints = 60;

if (hitPoints <= 0) {
    // End the game.
} else if (hitPoints < 30) {
    // Warn the player that health is low.
} else {
    // Continue the game normally.
}

The program checks the conditions from top to bottom. As soon as it finds one that is true, it runs the corresponding code and skips the rest.

Because the order matters, we should usually check the most important or most restrictive condition first. In this example, we must check whether the player is dead before checking whether the player is merely low on health.

Lesson 6.3: Switch Statements

A switch statement is useful when one value can match several specific choices. 

const direction = "north";

switch (direction) {
    case "north":
        // Move up.
        break;

    case "south":
        // Move down.
        break;

    case "east":
        // Move right.
        break;

    case "west":
        // Move left.
        break;

    default:
        // Handle an unknown direction.
}

The switch statement checks the value of direction and runs the code under the matching case.

The break statement tells the program to stop after running that code. Without break, the program continues into the next case.

The default section runs when none of the cases match.

A switch statement is usually clearest when comparing one value against several exact choices. For more complicated conditions, an if statement is often easier to read.
