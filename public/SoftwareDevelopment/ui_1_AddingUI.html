1. Adding UI Elements

Lesson 12.1: Creating and Adding an Element

In this class, we will usually create interface elements using TypeScript. The basic process is simple:

  1. Create the element.
  2. Set its text, properties, and appearance.
  3. Add it to the page.

For example:

const message = document.createElement("p");
message.textContent = "Hello!";
message.style.background = "yellow";
message.style.padding = "10px";

document.body.append(message);

The browser provides the document object so that our code can work with the webpage. We use it to create an element and add that element to the page.

The first line creates a paragraph element. We then give it text and define how it should look. Finally, we add it to the webpage.

Lesson 12.2: Common Elements

The following table provides a quick reference for several common HTML elements.

Purpose Element
Display text "p", "span", "div", or "label"
Display an image "img"
Get one line of user input "input"
Get multiline user input "textarea"
Create a button "button"
Other user input "checkbox", "radio", or "select" / "option"

Displaying Text

const message = document.createElement("p");
message.textContent = "Welcome to my app!";
message.style.fontSize = "24px";

document.body.append(message);

Displaying an Image

const image = document.createElement("img");
image.src = "cat.jpg"; // src stands for source: the name or location of the image
image.width = 200;
image.height = 150;

document.body.append(image);

The shortened name src comes from the early days of programming, when short names were commonly used to save space.

We can control the image’s width, height, and other properties directly in TypeScript. Later, we will also learn how to store shared styling in CSS.

Creating a Text Input

const myInputTextField = document.createElement("input");
myInputTextField.type = "text";

document.body.append(myInputTextField);

The type property controls how the input behaves and how it appears. Other options include "password", "number", and "email".

To access the user-entered text in code, perhaps after a Submit button is pressed, use the input’s value property: 

const userEnteredText = myInputTextField.value;

Creating a Multiline Text Input

A textarea is an input field that allows the user to enter several lines of text. 

const commentsInput = document.createElement("textarea");
commentsInput.rows = 5;

document.body.append(commentsInput);

To access the user-entered text:

const userEnteredComments = commentsInput.value;

Creating a Label and Input

We usually place a label next to an input field. A label and input can also be connected so that clicking the label selects the corresponding input. 

const label = document.createElement("label");
label.textContent = "Name:";
label.htmlFor = "nameInput"; // Connect the label to the input with this id.

const input = document.createElement("input");
input.type = "text";
input.id = "nameInput";

document.body.append(label, input);

Creating a Button

const button = document.createElement("button");
button.textContent = "Submit";

document.body.append(button);

To respond to a click, add an onclick function to the button: 

button.onclick = () => {
    const userEnteredText = myInputTextField.value;
};

The code inside the function runs when the button is clicked.

Creating a Checkbox

const checkbox = document.createElement("input");
checkbox.type = "checkbox";

document.body.append(checkbox);

To check whether it is selected:

const isSelected = checkbox.checked;

Creating Radio Buttons

Radio buttons allow one option to be selected from a group. 

const easyOption = document.createElement("input");
easyOption.type = "radio";
easyOption.name = "difficulty";
easyOption.value = "easy";

const hardOption = document.createElement("input");
hardOption.type = "radio";
hardOption.name = "difficulty";
hardOption.value = "hard";

document.body.append(easyOption, hardOption);

Radio buttons with the same name belong to the same group. Selecting one option deselects the others.

Creating a Dropdown Menu

A dropdown menu uses a select element containing several option elements. 

const menu = document.createElement("select");

const easyOption = document.createElement("option");
easyOption.textContent = "Easy";
easyOption.value = "easy";

const hardOption = document.createElement("option");
hardOption.textContent = "Hard";
hardOption.value = "hard";

menu.append(easyOption, hardOption);
document.body.append(menu);

To access the selected value:

const selectedValue = menu.value;

Lesson 12.3: Moving Styles to CSS

We can define an element’s appearance directly in TypeScript: 

const message = document.createElement("p");
message.textContent = "Important Message";
message.style.background = "lightgray";
message.style.padding = "10px";
message.style.borderRadius = "8px";

document.body.append(message);

We can also store shared styling in a separate CSS file. To use a style from that file, we give the element the same class name used in the CSS.

TypeScript File

const message = document.createElement("p");
message.textContent = "Important Message";

// Use the style named message-style from the CSS file.
message.className = "message-style";

document.body.append(message);

CSS File

.message-style {
    background: lightgray;
    padding: 10px;
    border-radius: 8px;
}

In the CSS file, custom class names begin with a period: 

.message-style

The same CSS class can be reused by any element that should have the same appearance.

Lesson 12.4: Creating Elements in HTML

Web apps and webpages use the same basic tools: HTML, CSS, and JavaScript or TypeScript. The difference is often how those tools are used.

A traditional webpage is more like a document. HTML provides most of the text and structure, while CSS controls the layout and appearance. An app relies more heavily on code because the program decides what should appear on the screen and changes it as the user interacts with it.

In this class, we will focus primarily on building apps and creating elements with TypeScript. However, it is useful to understand the more traditional web approach, where HTML defines what begins on the page, CSS controls how it looks, and TypeScript handles the interactivity.

This approach commonly uses three files:

  • HTML defines what begins on the page.
  • CSS defines how it looks.
  • TypeScript connects the page to our code.

HTML File

<!-- The id allows us to find this element in TypeScript. -->
<!-- The class connects this element to styling in the CSS file. -->

<p id="welcomeMessage" class="welcome-message">Welcome</p>

CSS File

/* Custom classes begin with a period. */

.welcome-message {
    font-size: 24px;
    font-weight: bold;
}

.warning-message {
    background: yellow;
    padding: 10px;
}

.large-button {
    font-size: 20px;
}

/* Add any other reusable styles here. */

To connect an HTML element to a CSS style, we give it the matching class name: 

<p class="welcome-message">Welcome</p>

The id serves a different purpose. It allows us to find and connect a particular HTML element to our TypeScript code.

TypeScript File

const userName = "Jon Snow";

// Find the HTML element whose id is welcomeMessage.
const welcomeMessage = document.getElementById("welcomeMessage");

if (welcomeMessage !== null) {
    welcomeMessage.textContent = "Welcome " + userName;
}

The HTML places the paragraph on the page. The CSS controls its appearance. The TypeScript finds the paragraph using its id and updates the text.
