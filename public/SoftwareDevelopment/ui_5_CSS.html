6: CSS QUICK REFERENCE

CSS stands for Cascading Style Sheets. HTML defines the elements on a webpage, while CSS defines how those elements look and how they are arranged.

The word cascading refers to the way CSS combines multiple rules and decides which value should be used when more than one rule affects the same property.

Students should understand the basic structure of CSS and recognize the properties we use regularly. There is no need to memorize every available property. For more complicated styling, layouts, or effects, we can use reference materials or AI and then read through the result to understand what it changes.

Lesson 6.1: CSS Rules

A CSS rule connects a name with one or more styling instructions. 

.message {
    background: lightgray;
    padding: 8px;
}

We can apply that style to an element in HTML:

<p class="message">Hello!</p>

Or to an element created in TypeScript:

const message = document.createElement("p");
message.className = "message";

A basic CSS rule follows this format:

.class-name {
    property: value;
}

The class name begins with a period in the CSS file. Inside the braces, each property is followed by a value and a semicolon.

In HTML and TypeScript, we use the class name without the period: 

<p class="message">Hello!</p>
message.className = "message";

Padding and Margin

Padding adds space inside an element, around its contents.

.message {
    padding: 12px;
}

Margin adds space outside an element, separating it from nearby elements. 

.message {
    margin: 12px;
}

Several Values

Some properties can accept more than one value.

.message {
    padding: 8px 16px;
}

The first value controls the top and bottom. The second controls the left and right. 

.message {
    margin: 8px 12px 16px 20px;
}

With four values, the order is:

  1. Top
  2. Right
  3. Bottom
  4. Left

Lesson 6.3: Applying More Than One Class

An HTML element can use more than one CSS class.

<button class="sidebar-item selected-item">
    Settings
</button>

The class names are separated by spaces. This button receives the rules from both sidebar-item and selected-item. 

.sidebar-item {
    padding: 8px;
    background: lightgray;
}

.selected-item {
    background: blue;
    color: white;
}

The first class provides the basic appearance of every sidebar item. The second class adds the appearance used for the selected item.

Both classes set the background color, so CSS must decide which value to use. In this simple example, the rule written later wins, and the background becomes blue. 

.sidebar-item {
    background: lightgray;
}

.selected-item {
    background: blue;
}

This process is part of the cascade. CSS combines all of the rules that apply to an element and determines which value should be used for each property.

More specific rules can override less specific rules, so the last rule does not always win. We do not need to memorize all of the rules yet. When a style does not appear as expected, another CSS rule may be overriding it.

Lesson 6.4: Changing Classes in TypeScript

We can change an element’s CSS classes while the program is running.

Adding a Class

myButton.classList.add("selected-item");

This adds selected-item without removing the element’s existing classes.

For example, the button may now have both classes:

<button class="sidebar-item selected-item">
    Settings
</button>

Removing a Class

myButton.classList.remove("selected-item");

This removes the selected appearance while leaving the other classes unchanged.

Replacing All Classes

myButton.className = "sidebar-item";

The className property replaces the complete list of classes. Use classList.add() or classList.remove() when we want to change one class without affecting the others.

Showing and Hiding Elements

We can hide an element using a CSS class:

.hidden {
    display: none;
}

Then add or remove that class in TypeScript:

myElement.classList.add("hidden");    // Hide the element.
myElement.classList.remove("hidden"); // Show the element.

Lesson 6.5: Reading CSS

Students do not need to memorize every CSS property. However, they should be able to read a CSS rule and determine what it is doing.

Consider the following example:

.sidebar-button {
    width: 150px;
    padding: 8px;
    background: blue;
    color: white;
    border: none;
}

We can read it one line at a time:

  • Apply these rules to elements using the class sidebar-button.
  • Set the width to 150 pixels.
  • Add 8 pixels of space inside the button.
  • Make the background blue.
  • Make the text white.
  • Remove the border.

When using CSS from a reference or AI, check four things:

  1. Which element or class does the rule affect?
  2. Which property is being changed?
  3. What value is being assigned?
  4. Could another rule be overriding it?

For example, AI might suggest:

.card {
    box-shadow: 0 2px 8px rgb(0 0 0 / 20%);
}

Students do not need to memorize the format of box-shadow. They should understand that the rule affects elements using the card class and adds a shadow.

The goal is to understand the structure well enough to use CSS safely, make basic changes, and recognize when a result does not match what we intended.
