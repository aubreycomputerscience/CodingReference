1. ARRAYS

An array stores several values in a specific order. For example, we can use one array to store the names of every animal in a game.

Lesson 1.1: Creating an Array

We create an array by placing items inside square brackets:

const animals = ["cat", "dog", "monkey"];

The items remain in the order in which they were added.

First:  "cat"
Second: "dog"
Third:  "monkey"

An array will normally contain one type of information. We can state that type explicitly: 

const animals: Array<string> = ["cat", "dog", "monkey"];
const scores: Array<number> = [10, 20, 30];

Read Array<string> as “an array of strings.”

Arrays preserve order, make it easy to add items, and allow us to work through an entire list using a loop.

Lesson 1.2: Accessing and Changing Items

INDEXES

Each item in an array has a numbered position called an index.

Array indexes begin at 0, not 1.

const animals = ["cat", "dog", "monkey"];

const firstAnimal = animals[0];  // "cat"
const secondAnimal = animals[1]; // "dog"
const thirdAnimal = animals[2];  // "monkey"

We can imagine the array like this:

Index:     0       1         2
Item:    "cat"   "dog"   "monkey"

Starting at 0 may initially seem strange, but it is standard in TypeScript and many other programming languages.

CHANGING AN ITEM

We can replace an item by using its index:

const animals = ["cat", "dog", "monkey"];

animals[1] = "tiger"; // Replace the second item.

The array now contains:

["cat", "tiger", "monkey"]

Even though animals was declared using const, we can change an item inside the array. The variable still refers to the same array.

WORKING THROUGH AN ARRAY

When we want to work with every item, we should normally use a for...of loop: 

const animals = ["cat", "dog", "monkey"];

for (const animal of animals) {
    if (animal === "dog") {
        // Do something with the dog.
    }
}

Each time the loop runs, animal contains the next item in the array.

Use an index when you need one particular position:

animals[0] = "tiger";

Use for...of when you want to work through the entire list. We should not manage indexes ourselves unless the position is actually important.

Lesson 1.3: Common Array Properties and Methods

QUICK REFERENCE

Property, method, or syntax Purpose
myArray.length Find the number of items
myArray.push(item) Add an item to the end
myArray.pop() Remove and return the last item
myArray.unshift(item) Add an item to the beginning
myArray.shift() Remove and return the first item
myArray.includes(item) Check whether an item appears in the array
myArray.slice(start, end) Copy part of an array
[...myArray] Copy the entire array

LENGTH

The length property tells us how many items are in an array: 

const animals = ["cat", "dog", "monkey"];
const numberOfAnimals = animals.length; // 3

length is a property, so it does not use parentheses.

ADDING AND REMOVING ITEMS AT THE END

The push() method adds an item to the end of an array: 

const animals = ["cat", "dog"];

animals.push("monkey");

The array now contains:

["cat", "dog", "monkey"]

The pop() method removes and returns the last item: 

const animals = ["cat", "dog", "monkey"];

const removedAnimal = animals.pop();

After this code runs:

animals:       ["cat", "dog"]
removedAnimal: "monkey"

If the array is empty, pop() returns undefined.

ADDING AND REMOVING ITEMS AT THE BEGINNING

The unshift() method adds an item to the beginning: 

const animals = ["dog", "monkey"];

animals.unshift("cat");

The array now contains:

["cat", "dog", "monkey"]

The shift() method removes and returns the first item: 

const animals = ["cat", "dog", "monkey"];

const removedAnimal = animals.shift();

After this code runs:

animals:       ["dog", "monkey"]
removedAnimal: "cat"

If the array is empty, shift() returns undefined.

Adding or removing items at the beginning is usually less efficient than working at the end because the remaining items must move to new indexes. For ordinary classroom projects, this usually will not matter.

CHECKING WHETHER AN ITEM EXISTS

The includes() method checks whether an array contains a particular item: 

const animals = ["cat", "dog", "monkey"];

const hasDog = animals.includes("dog");     // true
const hasTiger = animals.includes("tiger"); // false

The result is a Boolean value.

COPYING PART OF AN ARRAY

The slice() method copies part of an array without changing the original: 

const animals = ["cat", "dog", "monkey", "tiger"];

const selectedAnimals = animals.slice(1, 3);

The new array contains the items beginning at index 1 and stopping before index 3: 

selectedAnimals: ["dog", "monkey"]
animals:         ["cat", "dog", "monkey", "tiger"]

The ending index is not included.

COPYING AN ENTIRE ARRAY

Assigning an array to another variable does not create a new array: 

const originalAnimals = ["cat", "dog"];
const copiedAnimals = originalAnimals;

Both variables refer to the same array.

To create a separate array containing the same items, use the spread operator: 

const originalAnimals = ["cat", "dog"];
const copiedAnimals = [...originalAnimals];

Read this as:

Create a new array and place all the items from originalAnimals inside it.

Now changing copiedAnimals does not change originalAnimals: 

copiedAnimals[0] = "tiger";

// originalAnimals contains ["cat", "dog"]
// copiedAnimals contains ["tiger", "dog"]

This works as expected when the array contains primitive values such as strings, numbers, or Booleans. If an array contains objects, those objects have their own references. The two arrays are separate, but both arrays still point to the same objects inside them. We will return to this distinction after learning about objects.

Lesson 1.4: Finding and Transforming Items

Some array methods ask us to provide a small function describing what we want to find or change. These methods are powerful, but their notation is less obvious.

We will study functions separately. For now, this section can be used as a reference when these methods appear in code.

FIND

The find() method returns the first item that matches a condition: 

const numbers = [1, 2, 3, 4];

const foundNumber = numbers.find(number => number === 2);

The variable foundNumber contains 2.

The expression

number => number === 2

means:

Take each number and check whether it equals 2.

If no item matches, find() returns undefined.

FILTER

The filter() method creates a new array containing every item that matches a condition: 

const numbers = [1, 2, 3, 4, 5, 6];

const evenNumbers =
    numbers.filter(number => number % 2 === 0);

The new array contains:

[2, 4, 6]

The original array does not change.

We could perform the same basic task manually with a loop: 

const numbers = [1, 2, 3, 4, 5, 6];
const evenNumbers: Array<number> = [];

for (const number of numbers) {
    if (number % 2 === 0) {
        evenNumbers.push(number);
    }
}

The loop is longer, but its steps may be easier to understand when first learning.

MAP

The map() method creates a new array by transforming every item: 

const animals = ["cat", "dog", "monkey"];

const uppercaseAnimals =
    animals.map(animal => animal.toUpperCase());

The new array contains:

["CAT", "DOG", "MONKEY"]

The original array still contains:

["cat", "dog", "monkey"]

These methods can make code shorter, but a for...of loop is often easier for beginning programmers to read. Use for...of unless one of these methods clearly expresses what you want to do.

You may also encounter splice(), which can insert, remove, or replace items in an existing array. Its behavior depends on several positional arguments, so we will not use it as one of our primary array tools.
