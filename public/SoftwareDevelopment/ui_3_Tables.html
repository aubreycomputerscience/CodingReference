Chapter 3: Lists & Tables

Programs often store information in arrays. To display that information, we can loop through the array and create one element for each item.

This works especially well when the amount of data may change. If another item is added to the array, the program can automatically add another item to the screen.

Lesson 3.1: Building a List from Data

Suppose we have a list of animals:

const animals = ["Cat", "Dog", "Rabbit"];

We can loop through the array and create one visible element for each animal: 

function buildUI() {
    for (const animal of animals) {
        const animalText = document.createElement("p");
        animalText.textContent = animal;

        document.body.append(animalText);
    }
}

buildUI();

The loop runs once for each animal. During each loop, the program creates an element, adds the animal’s name, and places it on the page.

The data determines how many elements appear. If we add another animal to the array, the program creates another element the next time buildUI() runs. 

const animals = ["Cat", "Dog", "Rabbit", "Horse"];

If the list never changes, we could also write the items directly in HTML. Creating the list with TypeScript is useful when the program needs to add, remove, or update the items.

Lesson 3.2: Building a Table from Data

A table displays several pieces of related information in rows and columns.

Suppose we have an array of people:

type Person = {
    name: string;
    age: number;
};

const peopleData: Array<Person> = [
    { name: "Jon Snow", age: 24 },
    { name: "Arya Stark", age: 18 },
    { name: "Tyrion Lannister", age: 32 }
];

Each item stores a name and an age. We will discuss this format in greater detail later. For now, we only need to know that we can access the information using person.name and person.age.

We first create an element that will hold the rows:

const peopleView = document.createElement("div");
document.body.append(peopleView);

A div is a general-purpose element. It can act like a box that holds text or other elements. Here, peopleView holds the entire table.

Creating the Rows

We can now create one row for each person:

function buildPeopleTable() {

    // Remove the old rows before rebuilding the table.
    peopleView.replaceChildren();

    for (const person of peopleData) {
        const row = document.createElement("div");

        const name = document.createElement("div");
        name.textContent = person.name;

        const age = document.createElement("div");
        age.textContent = person.age.toString();

        row.append(name, age);
        peopleView.append(row);
    }
}

buildPeopleTable();

During each loop, the program creates a row. It then creates separate elements for the person’s name and age and places both of them inside the row.

This is our first example of placing elements inside another element: 

row.append(name, age);

The name and age are placed inside the row. The row is then placed inside peopleView.

Rebuilding the Table

If we rebuild the table, we must first remove the old rows: 

peopleView.replaceChildren();

Without this line, calling buildPeopleTable() a second time would add another copy of every row.

After changing the data, we can call the function again:

peopleData.push({ // Add an element to the end of the array.
    name: "Sansa Stark",
    age: 22
});

buildPeopleTable();

The old rows are removed, and the table is rebuilt using the updated array.

Arranging Each Row

By default, the name and age may not appear next to each other. We can tell the row to arrange the elements inside it from left to right: 

function buildPeopleTable() {

    // Remove the old rows before rebuilding the table.
    peopleView.replaceChildren();

    for (const person of peopleData) {
        const row = document.createElement("div");
        row.style.display = "flex";
        row.style.flexDirection = "row";
        row.style.padding = "6px 0";

        const name = document.createElement("div");
        name.textContent = person.name;
        name.style.width = "200px";

        const age = document.createElement("div");
        age.textContent = person.age.toString();
        age.style.width = "80px";

        row.append(name, age);
        peopleView.append(row);
    }
}

Setting display to "flex" allows us to control how the elements inside the row are arranged. Setting flexDirection to "row" places them from left to right. Giving the name and age a width keeps the values aligned in columns.

We will examine layout options in greater detail later.

Lesson 3.3: Creating a Table in HTML

A traditional webpage may define a table directly in HTML. This works well when the rows are known ahead of time and do not need to be created on the fly. 

<table class="people-table">
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>

    <tr>
        <td>Jon Snow</td>
        <td>24</td>
    </tr>

    <tr>
        <td>Arya Stark</td>
        <td>18</td>
    </tr>
</table>

The table uses four main HTML elements:

Element Purpose
table Contains the entire table
tr Creates a table row
th Creates a heading cell
td Creates a regular data cell

We can use CSS to add spacing and make the table easier to read: 

.people-table {
    border-collapse: collapse;
}

.people-table th,
.people-table td {
    padding: 8px 16px;
    text-align: left;
}

.people-table th:first-child,
.people-table td:first-child {
    padding-right: 32px;
}

The HTML class people-table connects the table to the matching rules in the CSS file.
