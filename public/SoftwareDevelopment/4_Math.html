Chapter 4: Math, Comparison, & Logic

Lesson 4.1: Math

BASIC OPERATIONS

TypeScript can perform the same basic mathematical operations that we use in ordinary arithmetic. 

const addition = 8 + 2;        // 10
const subtraction = 8 - 2;     // 6
const multiplication = 8 * 2;  // 16
const division = 8 / 2;        // 4

The symbols for addition and subtraction are familiar. Multiplication uses an asterisk (*), and division uses a forward slash (/).

We can also use variables in mathematical expressions:

const hitPoints = 100;
const incomingDamage = 30;

const remainingHitPoints = hitPoints - incomingDamage; // 70

ORDER OF OPERATIONS

TypeScript follows the normal order of operations. Multiplication and division are performed before addition and subtraction. 

const answer = 2 + 3 * 4; // 14

We can use parentheses when we want part of an expression to be performed first: 

const answer = (2 + 3) * 4; // 20

REMAINDERS

The remainder operator (%), sometimes called mod, gives us the remainder after division: 

const remainder = 10 % 3; // 1

The value is 1 because dividing 10 by 3 leaves a remainder of 1.

The remainder operator is especially useful when checking whether a number is even or odd: 

const remainder = 8 % 2; // 0

The value is 0 because 8 divides evenly by 2.

MATH FUNCTIONS

We can access a library of useful math functions by writing Math, followed by a period and the function we want to use. 

const roundedNumber = Math.round(4.6); // 5
const lowerNumber = Math.floor(4.9);   // 4
const higherNumber = Math.ceil(4.1);   // 5

The Math.round() function rounds to the nearest whole number.

The Math.floor() function rounds down, while Math.ceil() rounds up.

Math.random() creates a random number greater than or equal to 0 and less than 1. 

const randomNumber = Math.random(); // From 0 up to, but not including, 1

We will later use random numbers to create game events and other unpredictable behavior.

Lesson 4.2: Comparison

TRUE OR FALSE QUESTIONS

A comparison asks whether two values have a particular relationship. The result is a Boolean value—a truth value that is either true or false. 

const isGreater = 10 > 5; // true
const isLess = 10 < 5;    // false

TypeScript provides several comparison operators:

>    greater than
<    less than
>=   greater than or equal to
<=   less than or equal to
===  equal to
!==  not equal to

For example:

const playerHP = 50;

const isAlive = playerHP > 0;            // true
const isAtFullHealth = playerHP === 100; // false
const isInDanger = playerHP <= 20;       // false

ASSIGNMENT AND EQUALITY

TypeScript uses three equal signs (===) to ask whether two values are equal. 

const hasMaximumHP = playerHP === 100; // false

A single equal sign (=) assigns a value to a variable. 

let playerHP = 50;

playerHP = 100; // Assign the value 100 to playerHP.

Compare:

playerHP = 100;   // Assign a value.
playerHP === 100; // Ask whether the value is 100.

One changes the variable; the other asks a true-or-false question.

JavaScript also has a two-equal-sign operator (==) that attempts to convert values before comparing them. This can produce confusing results.

Never use ==. Use === when comparing values.

To ask whether two values are not equal, use !==. 

const hasNoHealth = playerHP !== 100; // false

COMPARING STRINGS

Strings can also be compared:

const animal = "cat";

const isCat = animal === "cat"; // true
const isDog = animal === "dog"; // false

String comparisons are sensitive to capitalization:

const isCat = "cat" === "Cat"; // false

The strings "cat" and "Cat" are not identical because one begins with a lowercase letter and the other begins with an uppercase letter.

Lesson 4.3: Logic

BOOLEAN LOGIC

A Boolean is a truth value: either true or false.

Logical operators allow us to combine or reverse Boolean values. The three most common logical operators are: 

&&   AND
||   OR
!    NOT

AND

The AND operator (&&) produces true only when both sides are true. 

const hasKey = true;
const knowsPassword = true;

const canEnter = hasKey && knowsPassword; // true

If either side is false, the result is false:

const hasKey = false;
const knowsPassword = true;

const canEnter = hasKey && knowsPassword; // false

OR

The OR operator (||) produces true when at least one side is true. 

const hasKey = false;
const knowsPassword = true;

const canEnter = hasKey || knowsPassword; // true

The player can enter because knowing the password is enough. The player does not also need a key.

NOT

The NOT operator (!) reverses a Boolean value. 

const gameIsOver = false;
const gameIsRunning = !gameIsOver; // true

Because gameIsOver is false, not false is true.

COMBINING LOGIC AND COMPARISONS

We can combine comparisons and logical operators:

const playerHP = 40;
const hasShield = true;

const isSafe = playerHP > 20 && hasShield; // true

The comparison playerHP > 20 produces true, and hasShield is also true. Therefore, isSafe is true.

Parentheses can make a more complicated logical expression easier to read: 

const canEnter =
    (hasKey || knowsPassword) && !doorIsBlocked;

Read this as:

The player has a key OR knows the password,
AND the door is not blocked.

Logical expressions often appear inside if statements, where they help a program decide what to do. We will use them more when we learn about if and else.
