4. PAGE LAYOUT

When designing a webpage or app, the first step is often to divide the screen into sections. We might place a header at the top, a sidebar on the left, and the main content beside it.

The basic idea is to start with the full page and divide it into boxes. Each box can then arrange the elements placed directly inside it.

For example:

Page
├── Header
└── Body
    ├── Sidebar
    └── Content

Laying out a page can be a little tricky because each box has two separate jobs. It must determine how much space it takes up, and it may also need to arrange the elements inside it. It is often easiest to build the layout one section at a time.

Lesson 4.1: Creating Boxes and Arranging Their Contents

A div is a general-purpose HTML element. It can display text, create a visible rectangle, or hold other elements. 

const myView = document.createElement("div");
myView.style.width = "200px";
myView.style.height = "100px";
myView.style.background = "lightgray";

document.body.append(myView);

Once a div has a width, height, and background, it acts like a visible box. A div can also hold other elements, allowing us to divide the page into sections and organize what appears inside each section.

Arranging Elements in a Row or Column

We can organize the elements inside a box in rows or columns. The following example places two labels next to each other: 

const row = document.createElement("div");

// Arrange the elements inside this box.
row.style.display = "flex";
row.style.flexDirection = "row";

const firstLabel = document.createElement("label");
firstLabel.textContent = "My Label A";
firstLabel.style.background = "purple";
firstLabel.style.padding = "8px"; // Add space inside the label around the text.

const secondLabel = document.createElement("label");
secondLabel.textContent = "My Label B";
secondLabel.style.background = "yellow";
secondLabel.style.padding = "8px"; // Add space inside the label around the text.

row.append(firstLabel, secondLabel);
document.body.append(row);

Setting display to "flex" tells the box to use this layout system for the elements inside it. Setting flexDirection to "row" places those elements from left to right. 

row.style.flexDirection = "row";

We can instead arrange the elements from top to bottom:

row.style.flexDirection = "column";

These settings affect only the elements directly inside the box. If one of those inner elements also needs to arrange its own contents, it must have its own display and flexDirection settings.

It is important not to confuse display = "flex" with flex = "1". 

row.style.display = "flex";

This controls how row arranges the elements inside it. 

row.style.flex = "1";

This controls how much space row takes up inside its parent. The similar names are unfortunate, but the two properties serve different purposes.

Lesson 4.2: Building a Page Layout

We will build a page with a header at the top and a body underneath it. The body will contain a sidebar and the main content.

Create the Full Page

const page = document.createElement("div");

// Use the full height of the screen.
page.style.height = "100vh";

// Arrange the header and body from top to bottom.
page.style.display = "flex";
page.style.flexDirection = "column";

document.body.append(page);

100vh means 100 percent of the visible height of the screen.

Add the Header

const header = document.createElement("div");
header.textContent = "My App";
header.style.background = "lightblue";
header.style.padding = "12px"; // Add space inside the header around its contents.
header.style.flex = "none";

page.append(header);

flex = "none" means that the header takes only the space needed to display its content, padding, and any width or height we give it. It does not expand to claim the remaining space.

Add the Body

const bodyView = document.createElement("div");

// Fill the space below the header.
bodyView.style.flex = "1";

// Arrange the sidebar and content from left to right.
bodyView.style.display = "flex";
bodyView.style.flexDirection = "row";

page.append(bodyView);

These properties perform two different jobs. flex = "1" tells bodyView how much space to take inside page. display = "flex" and flexDirection = "row" tell bodyView how to arrange the sidebar and content inside it.

The page arranges the header and body from top to bottom. The body then arranges the sidebar and content from left to right. The layout settings on page do not automatically control the elements inside bodyView.

Add the Sidebar

const sidebar = document.createElement("div");
sidebar.style.width = "150px";
sidebar.style.background = "whitesmoke";
sidebar.style.borderRight = "1px solid #cccccc";
sidebar.style.flex = "none";

bodyView.append(sidebar);

The sidebar asks for a width of 150 pixels. Since its flex value is "none", it does not expand to take additional space.

Add the Main Content

const content = document.createElement("div");
content.style.flex = "1";
content.style.padding = "16px"; // Add space inside the content area.

bodyView.append(content);

The content takes the space that remains after the sidebar takes its 150 pixels.

Complete Example

const page = document.createElement("div");
page.style.height = "100vh";
page.style.display = "flex";
page.style.flexDirection = "column";

const header = document.createElement("div");
header.textContent = "My App";
header.style.background = "lightblue";
header.style.padding = "12px";
header.style.flex = "none";

const bodyView = document.createElement("div");
bodyView.style.flex = "1";
bodyView.style.display = "flex";
bodyView.style.flexDirection = "row";

const sidebar = document.createElement("div");
sidebar.style.width = "150px";
sidebar.style.background = "whitesmoke";
sidebar.style.borderRight = "1px solid #cccccc";
sidebar.style.flex = "none";

const content = document.createElement("div");
content.textContent = "Main Content";
content.style.flex = "1";
content.style.padding = "16px";

bodyView.append(sidebar, content);
page.append(header, bodyView);
document.body.append(page);

This produces the following structure:

Page
├── Header
└── Body
    ├── Sidebar
    └── Content

Lesson 4.3: Claiming Space

Each element must determine how much space it should use inside its parent.

A fixed width or height asks for a specific amount of space:

sidebar.style.width = "150px";

A flex value asks for a share of the available space.

Setting Meaning
flex = "none" Take only the space needed for the content, padding, and any width or height.
flex = "1" Take one share of the remaining space.
flex = "2" Take two shares of the remaining space.

Suppose two elements share the remaining space:

firstView.style.flex = "1";
secondView.style.flex = "2";

The available space is divided into three shares. The first element receives one share, while the second receives two.

In the page example, the sidebar uses a fixed width:

sidebar.style.width = "150px";
sidebar.style.flex = "none";

The content takes everything that remains:

content.style.flex = "1";

This is a common layout pattern: one section has a fixed size, while another expands to fill the available space.

Lesson 4.4: Moving the Layout to CSS

We can build the same page in TypeScript while storing the layout and appearance in a separate CSS file.

TypeScript File

const page = document.createElement("div");
page.className = "page";

const header = document.createElement("div");
header.className = "header";
header.textContent = "My App";

const bodyView = document.createElement("div");
bodyView.className = "body-view";

const sidebar = document.createElement("div");
sidebar.className = "sidebar";

const content = document.createElement("div");
content.className = "content";
content.textContent = "Main Content";

bodyView.append(sidebar, content);
page.append(header, bodyView);
document.body.append(page);

CSS File

.page {
    height: 100vh;

    /* Arrange the elements inside the page from top to bottom. */
    display: flex;
    flex-direction: column;
}

.header {
    /* Take only the space needed to display the header. */
    flex: none;

    padding: 12px;
    background: lightblue;
}

.body-view {
    /* Take the remaining space below the header. */
    flex: 1;

    /* Arrange the elements inside the body from left to right. */
    display: flex;
    flex-direction: row;
}

.sidebar {
    /* Take a fixed amount of space inside the body. */
    width: 150px;
    flex: none;

    background: whitesmoke;
    border-right: 1px solid #cccccc;
}

.content {
    /* Take the space remaining beside the sidebar. */
    flex: 1;

    padding: 16px;
}

The structure is the same as before. TypeScript creates the elements and places them inside one another. The CSS file controls both how much space each element takes and how it arranges the elements inside it.

Lesson 4.5: Scrolling Inside a Section

Sometimes a section contains more information than can fit inside the available space.

We can allow that section to scroll:

content.style.overflow = "auto";

Or in CSS:

.content {
    flex: 1;
    padding: 16px;
    overflow: auto;
}

If the content fits, no scroll bar is needed. If the content becomes too large, the content section can scroll without changing the rest of the page layout.

A common full-page layout therefore looks like this:

body {
    margin: 0;
    padding: 0;
}

.page {
    height: 100vh;

    /* Arrange the page contents from top to bottom. */
    display: flex;
    flex-direction: column;
}

.body-view {
    /* Take the space remaining below the header. */
    flex: 1;

    /* Arrange the sidebar and content from left to right. */
    display: flex;
    flex-direction: row;

    overflow: hidden;
}

.content {
    /* Take the space remaining beside the sidebar. */
    flex: 1;

    overflow: auto;
}

The page fills the screen. The body fills the space below the header, and the content section scrolls when necessary.
