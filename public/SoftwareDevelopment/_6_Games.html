Chapter 6: Games

This section provides a quick reference for moving characters and other objects around the screen in a simple browser game. We will use keyboard input to control one character and a run loop to update other game elements over time.

Moving a Character with the Keyboard

// Run code
setupCharacter();

// My code
const myCharacter = document.createElement("img");
let x = 0;
let y = 0; // y starts at the top and increases as we move down.

function setupCharacter(): void {
    myCharacter.src = "images/character.png";
    myCharacter.style.position = "absolute"; // Allows us to use left and top.

    document.body.appendChild(myCharacter);
    updateCharacterPosition();
}

document.onkeydown = (event) => {
    switch (event.key) {
        case "ArrowLeft":
            event.preventDefault(); // Prevent the webpage from scrolling.
            x = x - 10;
            break;

        case "ArrowRight":
            event.preventDefault();
            x = x + 10;
            break;

        case "ArrowUp":
            event.preventDefault();
            y = y - 10;
            break;

        case "ArrowDown":
            event.preventDefault();
            y = y + 10;
            break;
    }

    updateCharacterPosition();
};

function updateCharacterPosition(): void {
    myCharacter.style.left = x + "px";
    myCharacter.style.top = y + "px";
}

Running the Game

A game uses a run loop to update the game repeatedly. The browser usually updates the display about 60 times per second. Before each update, we change the game state and update the properties of any HTML elements that need to change. 

// Run code
requestAnimationFrame(runLoop);

// My code
function runLoop(time: number): void {
    // Update the game state and HTML element properties.

    requestAnimationFrame(runLoop); // Run this function again before the next display update.
}

The browser passes the current animation time into the function. The time is measured in milliseconds.

Moving a Monster

We can use a run loop to move a monster across the screen.

// Run code
setupMonster();
requestAnimationFrame(runLoop);

// My code
const monster = document.createElement("img");

let monsterX = 300;
let monsterY = 100;
let lastMoveMadeAtTime = 0;

function setupMonster(): void {
    monster.src = "images/monster.png";
    monster.style.position = "absolute"; // Allows us to use left and top.

    document.body.appendChild(monster);
    updateMonsterPosition();
}

function runLoop(time: number): void {
    if (time - lastMoveMadeAtTime >= 1000) { // Move once every 1,000 milliseconds.
        lastMoveMadeAtTime = time;
        monsterX = monsterX - 20;
        updateMonsterPosition();
    }

    requestAnimationFrame(runLoop); // Run this function again before the next display update.
}

function updateMonsterPosition(): void {
    monster.style.left = monsterX + "px";
    monster.style.top = monsterY + "px";
}
