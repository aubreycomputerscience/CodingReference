Security Operations / Blue Team — SOC analysts, security analysts, threat hunters. They watch systems, investigate alerts, and figure out whether something bad is happening. The video you just watched is essentially this category. Offensive Security / Red Team — penetration testers, ethical hackers, vulnerability testers. They deliberately try to break into systems so the organization can fix weaknesses before criminals exploit them. This is probably the category students will find most immediately interesting. Incident Response & Digital Forensics — the people called when something actually has happened. They contain attacks, reconstruct what the attacker did, preserve evidence, and help recover systems. Cisco has a pretty good recent description of this work and specifically combines incident response with threat hunting and detection engineering. Security Engineering — people who actually build and configure defenses: cloud security, network security, identity/access systems, security automation, application security, etc. This is much closer to ordinary engineering than to “hacking.” Governance, Risk & Compliance (GRC) — audits, regulations, security policy, risk assessments, vendor reviews, figuring out what an organization must protect and whether it is doing so. I actually think this one is important for students because otherwise cybersecurity looks like an entirely technical occupation.
