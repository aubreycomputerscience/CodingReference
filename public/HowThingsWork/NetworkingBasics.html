Building a Network: From One Computer to the Internet

Rather than starting with dozens of networking terms and protocols, we can understand a network by building one piece at a time. Each new component solves a problem created by the previous step.

1. Start with One Computer

A computer by itself doesn't really need a network. It can process and store information locally, but it has nothing else to communicate with.

To create a network, we need another device.

2. Connect Two Computers

Connect two computers with an Ethernet cable and we have a very simple network.

Each computer needs an IP address so that software can identify the other computer. Because there is no system automatically assigning addresses yet, we can assign them manually.

IP Address — What is it?

An IP address is a number used to identify a device's location on a network. It allows computers to specify where network information is supposed to go.

For example:

  • Computer A: 10.0.0.1
  • Computer B: 10.0.0.2

These are static IP addresses because we assigned them ourselves.

Now the computers can communicate directly.

3. Add More Computers — The Switch

Suppose we want to add a third computer, then a fourth, then a fifth.

In theory, we could try connecting every computer directly to every other computer. But the number of connections would grow rapidly. With n computers, a fully connected network would require:

n(n − 1) / 2 connections

Ten computers would require 45 connections.

Instead, we use a switch.

Switch — What is it?

A switch is a device for connecting many devices on the same local network. Each computer plugs into the switch, and the switch sends information out the appropriate port. 

Computer A ──┐
Computer B ──┤
Computer C ──┼── SWITCH
Computer D ──┤
Computer E ──┘

Now every new computer requires only one additional connection to the switch.

The switch learns which devices are connected to which ports and uses MAC addresses to determine where to send information.

MAC Address — What is it?

A MAC address is an identifier associated with a network interface, such as an Ethernet or Wi-Fi interface. Switches use MAC addresses to deliver information within a local network.

We now have a practical Local Area Network (LAN).

LAN — What is it?

A Local Area Network is a network covering a relatively limited area, such as a home, classroom, office, or building.

4. Connect Our Network to Another Network — The Router

Our computers can communicate with each other, but they still cannot reach anything outside their local network.

For that, we add a router.

Router — What is it?

A router connects different networks. It examines IP addresses and decides where information should be sent next to reach another network. 

Computers
    │
    ▼
  Switch
    │
    ▼
  Router

This gives us an important distinction:

A switch connects devices within a local network.
A router connects different networks.

For our computers, the router also becomes their default gateway.

Default Gateway — What is it?

The default gateway is the router a device sends information to when the destination is outside its own local network. Think of it as the network's exit door.

5. Stop Assigning Addresses by Hand — DHCP

Manually entering an IP address on every computer would quickly become annoying.

So networks commonly provide an automatic address service called DHCP (Dynamic Host Configuration Protocol).

DHCP — What is it?

DHCP automatically gives devices the network settings they need. Most importantly, it assigns them IP addresses so that an administrator doesn't have to configure every device manually.

DHCP can provide information such as:

  • an IP address
  • subnet information
  • the default gateway
  • the DNS server to use

On a home network, the home router commonly provides this service.

A simple way to remember it is:

DHCP gives out addresses.

6. Connect to the Internet

Our router can now connect our Local Area Network to an Internet Service Provider (ISP).

ISP — What is it?

An Internet Service Provider is the company or organization that connects your network to the larger Internet. 

Computers → Switch → Router → ISP → Internet

The Internet is not one giant local network. It is a network of networks.

At a very high level, routers connect those networks together:

Our LAN
   │
 Router
   │
 ISP
   │
 Router
   │
 Router
   │
 Router
   │
Another Network

The real Internet is much more interconnected than this simple chain. There are many possible paths between networks.

7. Stop Memorizing IP Addresses — DNS

Technically, computers can communicate using IP addresses. But people don't want to remember numerical addresses for every website they visit.

We would rather type a name such as google.com.

That creates another problem:

How do we find the IP address associated with that name?

We use DNS (Domain Name System).

DNS — What is it?

DNS is the Internet's name service. It translates names such as google.com into IP addresses that computers can use. You can think of it roughly as a shared Internet contact list. 

google.com
    ↓
   DNS
    ↓
IP address

This makes the difference between DHCP and DNS easier to remember:

DHCP: "I'm a new device. Give me an address."

DNS: "I know someone's name. What's their address?"

8. Use Internet Services

Once our computer has its network configuration and can find other computers by name, we can actually start doing useful things across the network.

For example, we can use the Web.

Web browsers and web servers communicate using HTTP or HTTPS.

HTTP/HTTPS — What is it?

HTTP is the protocol used to request and send web pages and other web resources. HTTPS is the secure, encrypted form normally used on the modern Web.

So visiting a website looks roughly like this:

Type a website name
        ↓
DNS finds its IP address
        ↓
Our computer sends traffic toward the router
        ↓
The router connects us to other networks
        ↓
Traffic crosses the Internet
        ↓
It reaches the web server
        ↓
HTTP/HTTPS handles the web communication

The Whole Story

We can build our understanding of networking as a sequence of problems and solutions:

One computer
Nothing to communicate with.

↓

Two computers + cable
Now they can communicate.

↓

More computers
Direct connections become increasingly complicated.

↓

Switch
One connection per device creates a manageable local network.

↓

Need to reach another network

↓

Router
Connects our network to other networks.

↓

Manually configuring every computer is tedious

↓

DHCP
Automatically gives devices addresses and network settings.

↓

Connect the router to an ISP

↓

Internet
Our network becomes one network among many interconnected networks.

↓

Humans don't want to remember IP addresses

↓

DNS
Translates human-friendly names into IP addresses.

↓

HTTP/HTTPS and other services
Now we can actually do useful things across the network.

The important idea is that none of these pieces is arbitrary. Each new piece solves a problem that appears as our network grows:

connect → organize → route → automate → find → communicate.
