Building a Network: From One Computer to the Internet

Rather than starting with dozens of networking terms and protocols, we can understand a network by building one piece at a time. We will begin with a single computer and add new components as we need them. Each new component solves a problem created as our network grows.

1. Start with One Computer

A computer by itself does not really need a network. It can process and store information locally, but it has nothing else to communicate with. To create a network, we need another device.

2. Connect Two Computers

If we connect two computers with an Ethernet cable, we have a very simple network. Each computer needs an IP address so that software can identify where information should go. Because there is no system automatically assigning addresses yet, we can assign them manually.

IP Address — What Is It?

An IP address is a number used to identify a device's location on a network. It allows computers to specify where network information is supposed to go.

For example:

  • Computer A: 10.0.0.1
  • Computer B: 10.0.0.2

These are static IP addresses because we assigned them ourselves. With an address for each computer, the two machines can communicate directly.

3. Add More Computers — The Switch

Adding a third, fourth, or fifth computer creates a new problem. In theory, we could connect every computer directly to every other computer, but the number of connections would grow rapidly. With n computers, a fully connected network would require:

n(n − 1) / 2 connections

Ten computers would already require 45 connections. Instead, we use a switch.

Switch — What Is It?

A switch connects many devices on the same local network. Each computer plugs into the switch, and the switch sends information out the appropriate port. 

Computer A ──┐
Computer B ──┤
Computer C ──┼── SWITCH
Computer D ──┤
Computer E ──┘

Now each new computer requires only one additional connection to the switch. The switch learns which devices are connected to which ports and uses MAC addresses to determine where to send information.

MAC Address — What Is It?

A MAC address is an identifier associated with a network interface, such as an Ethernet or Wi-Fi interface. Switches use MAC addresses to deliver information within a local network.

With the switch in place, we now have a practical Local Area Network (LAN).

LAN — What Is It?

A Local Area Network is a network covering a relatively limited area, such as a home, classroom, office, or building.

4. Connect Our Network to Another Network — The Router

Our computers can now communicate with each other, but they still cannot reach anything outside their local network. To connect our LAN to another network, we add a router.

Router — What Is It?

A router connects different networks. It examines IP addresses and decides where information should be sent next to reach another network. 

Computers
    │
    ▼
  Switch
    │
    ▼
  Router

This gives us an important distinction: A switch connects devices within a local network. A router connects different networks.

For the computers on our LAN, the router also becomes their default gateway.

Default Gateway — What Is It?

The default gateway is the router a device sends information to when the destination is outside its own local network. Think of it as the network's exit door.

5. Stop Assigning Addresses by Hand — DHCP

Manually entering an IP address and other network settings on every computer would quickly become tedious. Networks therefore commonly provide an automatic configuration service called DHCP (Dynamic Host Configuration Protocol).

DHCP — What Is It?

DHCP automatically gives devices the network settings they need. Most importantly, it assigns IP addresses so that an administrator does not have to configure every device manually. DHCP can also provide subnet information, the default gateway, and the DNS server the device should use.

On a home network, the home router commonly provides this service. A simple way to remember DHCP is: DHCP gives out addresses.

6. Connect to the Internet

Our router can now connect our Local Area Network to an Internet Service Provider (ISP).

ISP — What Is It?

An Internet Service Provider is the company or organization that connects your network to the larger Internet. 

Computers → Switch → Router → ISP → Internet

The Internet is not one giant local network. It is a network of networks. At a very high level, routers connect those networks together: 

Our LAN
   │
 Router
   │
 ISP
   │
 Router
   │
 Router
   │
 Router
   │
Another Network

The real Internet is much more interconnected than this simple chain. There are many possible paths between networks, but the basic idea remains the same: routers move information from one network toward another until it reaches its destination.

7. Stop Memorizing IP Addresses — DNS

Computers can communicate using IP addresses, but people do not want to remember a numerical address for every website they visit. We would rather type a name such as google.com. That creates another problem: How do we find the IP address associated with that name? We use DNS (Domain Name System).

DNS — What Is It?

DNS is the Internet's name service. It translates names such as google.com into IP addresses that computers can use. You can think of it roughly as a shared Internet contact list. 

google.com
    ↓
   DNS
    ↓
IP address

This also makes the difference between DHCP and DNS easier to remember:

DHCP: "I'm a new device. Give me an address."
DNS: "I know someone's name. What's their address?"

8. Use Internet Services

Once our computer has its network configuration and can find other computers by name, we can begin doing useful things across the network. One of the most familiar examples is the Web. Web browsers and web servers communicate using HTTP or HTTPS.

HTTP/HTTPS — What Is It?

HTTP is the protocol used to request and send web pages and other web resources. HTTPS is the secure, encrypted form normally used on the modern Web.

Visiting a website therefore looks roughly like this:

Type a website name
        ↓
DNS finds its IP address
        ↓
Our computer sends traffic toward the router
        ↓
The router connects us to other networks
        ↓
Traffic crosses the Internet
        ↓
It reaches the web server
        ↓
HTTP/HTTPS handles the web communication

The Whole Story

We can now see networking as a sequence of problems and solutions. We begin with one computer, which has nothing else to communicate with. Connecting two computers with a cable creates a simple network, but adding more computers makes direct connections increasingly complicated. A switch solves that problem by allowing every device to make one connection to a shared local network.

Once we want to communicate outside that network, we need a router, which connects our LAN to other networks. Configuring every device by hand quickly becomes tedious, so DHCP automatically provides addresses and other network settings. Connecting the router to an ISP makes our LAN part of the larger Internet, a network made up of many interconnected networks.

People do not want to remember numerical IP addresses, so DNS translates human-friendly names into those addresses. Finally, protocols such as HTTP and HTTPS allow us to use services across the network.

The important idea is that none of these pieces is arbitrary. Each new component solves a problem that appears as our network grows: connect → organize → route → automate → find → communicate.
