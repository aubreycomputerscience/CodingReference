Careers in Software Development

Software developers build the applications, websites, games, and other digital products people use every day. Although job titles vary, the work usually involves designing software, writing code, testing features, fixing problems, and improving products over time.

Example Careers

  • Software Developer — builds computer programs and applications.
  • Web Developer — builds websites and web applications.
  • Mobile App Developer — creates apps for phones and tablets.
  • Game Developer — develops the software behind computer and video games.

Software development is also a team effort. Developers commonly work with designers, user researchers, product managers, and other specialists to decide what to build and how it should work.
