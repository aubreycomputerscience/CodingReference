Popular Programming Langages C - The mother langage, including if statements, function calls, and loops. Every language on this list is based on C, borrowing basic syntax and grammar. JavaScript - Used primarily in webpages and web apps. Lightweight, easy to use, but poorly structured, optimized, and generally unsafe. Originally designed for writing little scripts, not for application development. TypeScript - JavaScript + Type checking. An attempt to address the shortcomings of JavaScript. Not perfect, but meets basic requirements and remains fairly lightweight and easy to use. Swift - Used to program iPhone apps and Mac applications. Emphasizes safety and performance, but introduces additional complexity and has a hard learning curve. From the perspective of a front end developer, it is difficult to use and over-engineered. Apple has invested hundreds of millions of dollars on it. Java - Used to write backend code and to write Android Apps (although Kotlin is preferred). Highly structured code suitable for complex applications. Heavy implementation and emphasis on object oriented approaches that have largely fallen out of favor. Kotlin - Used to create Android apps. Sophisticated, modern language. (I have limited experience with it.) C++ - An updated version of C that doesn't feel quite so 1970s. A little bit tricky to work with. C# - Microsoft's version of C, used to build Windows applicaitons. (I am largely unfamiliar with it, although being a C-based language, is fairly standard.) Python (My hot take): Formally used by univsersity professors who didn't want to keep up with modern programming practices and/or thought they were too hard to teach. Now used for AI and increasingly for backend servers. Like JavaScript, half-baked programming language for ametures, develops into industry standard. Lightweight, easy to use, but feels like it was made my a college kid. Other Languages Small-Talk - the first object oriented language. Fun to think about and expore. Haskel - a functional language (totally different feel from C).
