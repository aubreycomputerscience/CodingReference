Computer Hardware

1. The Major Components

A modern computer can be thought of as several major components working together:

Component Basic Function
CPU (Central Processing Unit) General-purpose processing; executes program instructions
GPU (Graphics Processing Unit) Massive parallel processing, originally developed primarily for graphics
NPU (Neural Processing Unit) Specialized, power-efficient processing for AI workloads
RAM (Memory) Fast temporary working space for programs and data
Storage (SSD) Long-term storage for programs, files, and the operating system
Motherboard Connects the major components and allows them to communicate
Power Supply Converts and distributes electrical power to the components
Cooling Removes heat produced by the CPU, GPU, and other components
Input/Output (I/O) Allows the computer to interact with people and other devices

Peripherals is the general term for many external input/output devices, such as keyboards, mice, monitors, and printers.

A computer may also have networking hardware, either integrated into the motherboard or provided through a separate network adapter.

2. RAM vs. Storage

RAM is the computer's short-term working memory.

  • Very fast
  • Used by currently running programs
  • Data is normally lost when power is removed
  • Common capacities include 16 GB, 32 GB, and 64 GB
  • Modern systems commonly use DDR4 or DDR5 memory

RAM = working space    |    Storage = long-term space

DDR5 is a newer generation of memory technology than DDR4. Changes to the memory circuitry and signaling allow higher data-transfer rates and improved efficiency.

Desktop computers generally allow RAM modules to be replaced or upgraded. Many laptops have RAM soldered directly to the motherboard, making upgrades difficult or impossible.

3. CPU

The CPU is the computer's general-purpose processor. It is designed to handle a very wide variety of instructions and tasks.

Core Count

A CPU can have multiple independent processing cores. More cores allow more work to happen concurrently, although more cores do not automatically make every individual task faster.

For example, suppose you need to add up a long grocery bill:

  1. Divide the list into four sections.
  2. Four workers each add one section.
  3. Combine the four results.

Multiple cores work on a similar principle: some problems can be divided into independent pieces that can be processed at the same time.

Clock Speed

Clock speed is measured in GHz. It indicates how quickly the processor's clock cycles occur, but clock speed alone does not tell you how fast a CPU is. Different processor designs can accomplish different amounts of work during each clock cycle.

Architecture

The architecture is the overall design of the processor. Two processors can have the same number of cores and the same clock speed but perform differently because their underlying designs differ.

CPU performance depends on more than GHz.

4. GPU

The GPU was originally developed primarily to handle the enormous amount of parallel computation required for computer graphics.

Modern GPUs are also extremely useful for AI because many AI operations involve performing the same kinds of mathematical operations on enormous amounts of data simultaneously.

CPU → flexible, general-purpose processing
GPU → massive parallel processing

This is one reason GPUs became so important to modern AI.

5. How 3D Graphics Work

A video game does not normally store a 3D object as a giant picture. Instead, a game stores a 3D model, or mesh, describing the object's geometry.

A mesh is constructed from geometric primitives, especially triangles. A complicated object can contain thousands or millions of triangles.

Triangle ≠ pixel

A triangle is part of the geometry of an object. A pixel is one of the individual dots that eventually make up the image displayed on the screen.

A triangle might cover only a few pixels when it is far away, but thousands of pixels when it is close to the camera. There is no fixed "size" for a triangle.

6. From 3D Model to Screen Image

Each frame of a game involves turning the 3D description of the world into a 2D image.

3D model → position and transform → triangles on screen → pixels → final image

The computer performs mathematical operations to determine things such as:

  • Where is the object?
  • How large does it appear?
  • What direction is it facing?
  • Where is the camera?
  • Which pixels are covered by each triangle?
  • What color should those pixels be?
  • How are lighting, textures, and shadows applied?

The computer repeatedly performs mathematical calculations to move, rotate, scale, and draw the objects in the scene.

Matrices are one mathematical tool used to perform these transformations, but understanding matrices is not necessary to understand the basic process.

7. Rasterization and Shading

Once the GPU knows where a triangle appears on the screen, it determines which pixels are covered by that triangle. This process is called rasterization.

The GPU then calculates the appearance of those pixels. This can involve:

  • Color
  • Textures
  • Lighting
  • Shadows
  • Reflections
  • Other visual effects

Shading can involve running mathematical programs for individual pixels or groups of pixels.

The GPU performs enormous numbers of related calculations in parallel.

8. Level of Detail

The game engine does not necessarily use the most detailed version of every object all the time.

An object close to the camera might use a highly detailed mesh containing many triangles. The same object far away might use a much simpler mesh because the viewer would not be able to see all of that detail anyway.

This is called Level of Detail (LOD).

Game engine → decides what geometry to use
GPU → processes and renders that geometry

9. GPU and AI

The same characteristic that makes GPUs useful for graphics—massive parallelism—also makes them useful for AI.

AI models perform enormous numbers of mathematical operations, including matrix and tensor operations. GPUs are well suited to this because they can perform many operations simultaneously.

Graphics → highly parallel GPUs → general-purpose GPU computing → GPUs heavily used for AI

10. NPU

Modern computers increasingly include an NPU (Neural Processing Unit).

An NPU is a specialized processor designed specifically for AI-related workloads. It is not a neuromorphic brain-like computer. It is conventional digital hardware optimized for particular types of AI computation.

GPU NPU
Powerful parallel processor Specialized AI processor
Flexible Designed for efficiency
High throughput High performance per watt
Excellent for graphics and large AI workloads Especially useful for on-device AI
Can consume substantial power Well suited to continuous AI features on battery-powered devices

Both GPUs and NPUs can perform AI inference. It is therefore not correct to think:

GPU = AI training
NPU = AI inference

A better simplification is:

GPU = powerful and flexible parallel processor
NPU = specialized and power-efficient AI processor

The computer's software can choose the processor that makes the most sense for a particular workload.

11. Data Movement Matters

One important reason specialized processors can be efficient is that moving data can consume significant time and energy.

A processor does not simply perform calculations without interacting with memory. Modern processor design therefore pays considerable attention to:

  • Where data is stored
  • How quickly it can be accessed
  • How much data must be moved
  • How efficiently intermediate results can flow through the processor

Some specialized AI hardware uses architectures such as systolic arrays, where intermediate results can flow directly between processing elements rather than repeatedly traveling back to external memory.

You do not need this level of detail for an introductory understanding, but it helps explain why specialized AI hardware can sometimes be substantially more efficient than running the same workload on a general-purpose processor.

12. Apple Silicon and Modern Processor Integration

Modern processors increasingly combine several types of processing hardware into a single package or system-on-a-chip (SoC).

For example, an Apple Silicon processor can contain:

  • CPU cores
  • GPU cores
  • Neural Engine / NPU
  • Memory controllers
  • Other specialized hardware

This differs from the traditional desktop model in which many components were installed as separate chips or cards.

The general trend is toward greater integration and specialization.

The Big Picture

Processor Primary Role
CPU Flexible, general-purpose processing
GPU Massive parallel processing
NPU Specialized, efficient AI processing

These processors work with RAM, which provides temporary working space, while storage holds programs and information long-term.

For graphics, the overall process can be summarized as:

3D model / mesh → transform geometry → triangles on screen → rasterization → shading → pixels → final image
